# 云港小事 · citylife

一个 AI 驱动的中文生活模拟游戏：**四个住户在同一座城市里自主生活，玩家不操作任何人，只看**。
台词由大模型实时生成（目前经中转服务），行为由本地代码决定；整个游戏是**一份单文件 HTML**，
不装包、不跑构建。

> 本仓库现在是**本地项目**：唯一真相源在本机 `F:\资料\codex\云港小事\citylife`，
> GitHub 只作**备份出口**（收工推一次），不再是工作台。
> 规矩见 `宪法.md`；项目现状与挂账见 `待办.md`；历史与口径见 `交接说明.md`——这三份叫「三件套」。

---

## 怎么跑

```
直接双击  city-life-framework.html
```

游戏就在这一个文件里（样式、脚本、SIM 全内联），双击即玩。素材是 `assets/` 里的两张拼合图，
缺了会自动回落成色块，不会崩。

> 注：**AI 文案在本地跑不通**——密钥只在托管环境的环境变量里，本地打开会在日志墙看到
> 「AI 连线失败（网络不通，已用模板兜底）」。此时四个住户说的话走**兜底文案池**，
> 其余行为（作息、工作、社交、天气、剪辑、离线追帧）全部照常。这条已登记在待办里。

## 怎么跑门禁（改完代码必跑）

```
F:\资料\codex\云港小事\run-gate.bat
```

**九步**：解包内联脚本 → 语法检查 → 无头模拟（`harness.js`）→ 30 天退化（`sim30.js`）→
走位三铁律（`walkgate.js`）→ 中转函数语法 → 涨号铁律（`versiongate.js`）→ SIM 块纯净 →
行号引用（`linegate.js`）；末尾另印**世界指纹**（`worldsig.js`）。

判绿看最后一行：**「门禁全绿」**。记录全文自动落在 `F:\临时\<日期>\门禁\`，含命令、时间、HEAD、
HTML sha256、Node 版本与每一步的完整输出。

单独跑某一步也可以：`node harness.js` / `node sim30.js` / `node walkgate.js` /
`node versiongate.js` / `node linegate.js` / `node worldsig.js`
（`harness.js` 等依赖解包出来的 `app.js`，跑一次门禁即会生成）。

## 改代码要守的几条（详见 `宪法.md`）

- **涨号铁律**：只要 `city-life-framework.html` 的字节改了，界面上的版本号就必须涨一位，
  并跑 `node versiongate.js --登记` 入表；只改 `.md` 或门禁脚本的单不涨号。
- **指纹两分**：**世界指纹**（`node worldsig.js`）只在世界行为或 rng 流真的变了时才变；
  **门禁指纹**（`node sim30.js` 的输出取 md5）连门禁措辞都算在内。
- **走位三铁律**：单帧位移不超上限 / 全程脚底不进实体格与家具占格 / 显示位置只有一个来源。
  `walkgate.js` 有源码级反向断言，改动 `draw()` 一带前先读它。
- **世界侧（SIM）改动＝大改动**：先出方案、等决策者点头；世界指纹必变，且 `sim30` 的阈值一行不许调。
- **每条新闸都要反向自查**：复演病态写法必须当场判红，再喂生产原文必须不误伤。
  一条恒绿的闸等于没立。
