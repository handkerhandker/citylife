# 第 205 单 · "顶上那条深色条"＋"横屏左侧空白" —— v159 → **v160**

> 一句话：决策者两条反馈，一个是**我们自己画的**、一个是**让多了**——① 顶上那条深色条
> 不是摄像头参数，是壳里第二十几单加的**顶部渐隐层**（按状态栏高度盖实心底色 `#171C26`，
> 比顶栏底色深）；② 横屏左侧 37px 空白是**左右安全区让位**（系统报的 l=37，疑为挖孔或宿主
> 残留旧值）。改法：**整段删掉渐隐层** ＋ **`量insets()` 末尾把左右归零**（上下照旧让位——
> 状态栏/手势条是真会压住字）。

## 一 · 证据链（两条反馈各自的归因）

1. **"上面顶不到顶部…你不用避让摄像头啊！！！"**
   - 查壳源码：`顶渐隐` 字段／`建顶渐隐()`／`调渐隐()`／`渐隐层` 类**全是我们自己写的**
     （按状态栏高度盖一条实心底色，比顶栏底色深一档）——决策者看到的深色条就是它；
   - 摄像头（挖孔）只影响**读数**（insets 数值），并不画任何条——"避让摄像头的参数"不存在，
     是这条自画渐隐层在背锅。**删它。**
2. **"横屏左侧空白过多，显得太宽，且左侧文字未顶到最左侧"**
   - 204 单的真机读数：横屏 `壳 t37 b16 l37 r0`——**l37** 是系统报的左右 inset；
     页面按它给 UI 让位 ⇒ 左侧那截空白。按决策者口令：**左右不再让位**（侧栏/浮层贴屏边）。

  ② `量insets()` 末尾加 **`左 = 0; 右 = 0;`**——两条分支（SDK≥30 与旧版回退）之后**无条件覆盖**；
     上/下照旧（状态栏/手势条真会压住字）。

  状态栏／顶部渐隐已去／横屏左右不再避让）。
