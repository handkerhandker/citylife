# 第 148 单 · 江灯节烟花（夜空的"看得见的高潮"）——v122 → **v123**

> 一句话：同类里"节日夜空要有看得见的高潮"是标配（出处见下），而本作的江灯节（D45 19:00–23:00）
> 此前只有播报、日志与灯影——**河上夜空是空的**。本单给节日夜加一层纯渲染的**江上烟花**：
> 每 2.6 秒一发、沿江面六个爆点轮转，上升曳光 → 炸开（14 道光芒＋白芯＋地面微光）。
> 纯 DOM 渲染层：零 rng、零存档字段、不改 SIM——三指纹逐字节原样。

## 一 · 出处（调研，2026-10-04 HTTP 200 复核）

Nookipedia·Fireworks show：

> "During a fireworks show, fireworks can be seen flying into the sky in the background and
> exploding in different colors, **lighting up the ground** and the insides of certain buildings."

同页另有 "The fireworks show … is an event held regularly…"。直接采纳两点：① 节日夜要有**看得见**的
高潮（而不是只有文字播报）；② "炸开的花色会照亮地面"——本作用**径向地面微光**呼应（画在夜色/灯光
罩层之上的自发光层）。

## 二 · 实现（`/*FIREWORK-START*/…/*FIREWORK-END*/`，一处定义）

| 件 | 做法 |
|---|---|
| 周期与相位 | `FIREWORK={周期:2600, 起爆:0.22}`：每 2.6 秒一发，前 22% 上升、其后炸开渐隐；全确定性（无 rng） |
| 爆点 | 六处固定点表轮转，**全在江面**（y=25.2–25.9；harness 有"y∈[24,28)"构造断言，"挪到岸上"当场判红） |
| 画面 | 上升曳光＋炸开 14 道光芒（两圈错开）＋白芯闪光＋ `createRadialGradient` 地面微光 |
| 两道 gate | `state.reduceMotion || !Sim.inFestival(w)` ⇒ 减少动态时整段跳过；只在节日夜画 |
| 层级 | `draw()` 收尾链排在 `streetGlow` 之后（最上层、自发光）——灯与光斑都压不住它 |
| 射程 | 只画布、零素材、零 SIM 写入、零存档字段 |
