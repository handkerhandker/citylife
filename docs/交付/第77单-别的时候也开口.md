# 第 77 单 · 别的时候也开口（生日／放灯／目标达成各留一句）

> 一句话：第 76 单那条"他→你"的通道只在"一周没来信"时用（一周最多四句，存在感很淡）。
> 本单加一处**每天 21:00** 的结算：今天若有一件值得跟你说的事——**今天他生日**、**今晚他放了灯**、
> **这周想做的事做到了**——就留一句，走**同一条往来记录**。
> 口径：**一天最多一句**（与"惦记"共用额度）、零 AI、零 rng、不改任何行为。
> 指纹：**只有 SIM 块 md5 变**（`87e87c8d…` → **`34bc6177…`**），世界 `b5935386…` 与门禁 `d759a1f6…` **逐字节原样**。
> 版本：v74 → **v75**。

## 一 · 缘由

第 76 单交付时登记的第一条就是它：**"留言只挂在'惦记'这一个触发上（生日／节日／大事都不会主动开口）"**。
一个只会在一周没收到你消息时才说话的人，还是太被动。

## 二 · 设计

```js
const NOTE={ at:21*60 };                       // 每天 21:00 结算一次
const NOTE_LINES={ bday:[…2 句…], fest:[…2 句…] };
function noteStep(w){
  if(PURE.minuteOfDay(w.t)!==NOTE.at) return;
  for(const ag of w.agents){
    if(ag.noteDay===d) continue;               // 一天最多一句（惦记那句已留过就跳过）
    if(inBirthday(w,ag))                          话=…bday…;
    else if(ag.lastFest 当天 && 放过灯)            话=…fest…;
    else if(ag.lastGoalOut 当天 && k==='done')     话='这周想做的事做到了：'+label+'。';
    if(!话) continue;
    ag.noteDay=d;  pushLog(w,{type:'player',sms:'note',…});
  }
}
```

| 由头 | 判据 | 数据来源 |
|---|---|---|
| 今天他生日 | `inBirthday(w,ag)` | 第 64 单那张生日表（**不依赖"买没买蛋糕"**——第一版挂在蛋糕上，21:00 前未必买上，成了一条会说谎的话） |
| 今晚他放了灯 | `ag.lastFest.t` 是**今天** | 第 62 单的落点（照"落笔抄录"口径） |
| 这周想做的事做到了 | `ag.lastGoalOut.t` 是今天且 `k==='done'` | 第 54 单的落点；留言里**带上那件事的名字** |

**取句**：把**人名**拌进序号（`日号 + id`）——第一版只用日号，结果四个人在江灯节当晚说出一字不差的一句。
