# 第 184 单 · 诊断浮层（视口／安全区／帧率打在屏幕上）——v149 → **v150**

> 一句话：鸿蒙 NEXT 上**没有 adb**，真机出问题只能靠屏幕上的字（交接文档 §5.5 的建议）。
> 本单加一个**默认关闭**的诊断浮层：设置里点开，左上角打出
> 「视口×密度×布局档／壳推下来的安全区四值／当前屏／帧率＋p95／缩放／速度」——

## 一 · 改了什么

1. 新元素 `#dbg`（`position:fixed` 左上角，`pointer-events:none`，`display:none`，开了才显示）；
2. 设置页「视口调试」多一行「**诊断浮层 开关**」（状态存本设备 localStorage `citylife-dbg`，
   不进存档信封、不进世界）；
3. 取数与刷新挂在**主循环**里、**节流 4Hz**（60 帧环形缓冲算 fps 与 p95；不让浮层自己变成负担）。
