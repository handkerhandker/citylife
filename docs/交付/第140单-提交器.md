# 第 140 单 · 提交器（`tools/closeout/commit.cjs`）——**工作流工具、产品零改动 ⇒ 不涨号**（仍 v117）

> 一句话：137 收掉了"回写"，本单收掉"提交"——**消息只走文件**（`git commit -F`）、git 命令一律数组调用
> **不经 shell** ⇒ 引号／换行／反引号／`$`／全角引号这一整类"传递事故"从根上消失。
> 本单的提交与快照**就是由它自己完成的**（狗粮）。

## 一 · 它治的是什么（真事故＋同类风险）

| # | 现场 | 根因 |
|---|---|---|
| 1 | 第 136 单开工前：含**英文双引号**的提交消息被 PowerShell 拆包，git 把半截当 pathspec 拒了（`pathspec … did not match`） | 消息经 shell 传递，引号规则由 shell 解释 |
| 2 | 同族风险（还没炸过的） | 换行、反引号、`$`、全角引号、`%`、路径空格……每一种都可能被某一层 shell 改写 |
| 治法 | **让消息永远不经过 shell**：写进文件，`git commit -F <文件>`；`spawnSync('git', [数组])` 不经 shell | 这类事故**整类**消失，而不是"下次注意转义" |

## 二 · 工具做什么（`node tools/closeout/commit.cjs …`）

| 件 | 做法 |
|---|---|
| 消息 | `--消息=<文件>`；文件**必须非空**（空/纯空白 ⇒ 拒） |
| 前置 | 工作树**无改动 ⇒ 拒**（不产出空提交）；`git add -A` → `git commit -F 消息文件` |
| 预演 | `--试运行`：印工作树清单与**消息原文**，不落任何提交 |
| 备份 | `--快照`：提交成功后跑项目 `snapshot.ps1 -Force`（可 `--快照脚本=` 覆盖）；快照失败整体退出码红 |
| 回执 | 提交成功打印 `git log -1 --oneline` |
