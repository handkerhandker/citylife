# 第 170 单 · 自己研究一道菜（"试新菜"）——v137 → **v138**

> 一句话：《无心云志》公告卡 05 的候选落地——**在家做饭时约每 5 天一次**，居民会"自己研究一道"
> （按哈希从 24 道家常菜里取一道没做过的，记进自己的菜谱）；角色卡与详情多一行「拿手菜」。

## 一 · 出处（用户提供，登记在 `docs/规划/借鉴调研-2026-10-04.md` §五）

《无心云志》公告卡 05：「选食材、配调味／琢磨做法和火候／给新招牌起个名；可能整锅失败，
也可能做出招牌；**成功的原创菜谱……以后还能照着做**。」

**抄哪一条**：自家厨房里"自己研究一道"，并把它**留下来**（菜谱）。
**不抄哪一条**："整锅失败"**不做惩罚**——守本作宪法「不做被夺走的设计」：不扣钱、不丢料、
不掉心情；只保留"成了就写进本子"的正向记忆。
