# 第 76 单 · 居民主动开口（把"惦记"升级成"留句话给你"）

> 一句话：到上一单为止，这座城只有**你**会开口——你发短信，他们才答。本单开一条**他→你**的通道：
> 惦记时（周日 18:00、这一周你一条短信都没来）**给你留一句话**，走的是**同一条往来记录**
> （`type:'player'` ＋ `sms:'note'`）——**城市日志、短信页的往来记录、回城弹窗**三处都看得到。
> 顺手修掉一处反复假红的旧闸：生日问候改成"**同一天同一个人只问候一次**"。
> 指纹：**三个数全变**（世界 `f23e62ed…` → **`b5935386…`**、门禁 `90242cc8…` → **`d759a1f6…`**、
> SIM 块 md5 `43a742f3…` → **`87e87c8d…`**）——缘由写在第五节，**属预期**。
> 版本：v73 → **v74**。

## 一 · 缘由（单向的城，算不上陪伴）

待办里挂着"陪伴做穿不做广场"这条定位。可到现在为止，**居民从来不会主动找你**：
第 74 单只做到"他心里惦记"（一条独白），第 75 单把往来记录接上了——但那一栏里永远**只有你说的话**。
调研出处（2026-10-03 实测可访问）：Nookipedia·Friendship 把友谊定义成"**interacts**"（互动，双向）；
星露谷 wiki·Friendship 那条"不打招呼会掉"同样假定了**对方也在场**。本单补上这句。

## 二 · 设计（零 AI、零 rng、不新增字段）

```js
const MISS_NOTE={ work:[…2 句…], clerk:[…], trade:[…], write:[…] };   // 四类各 2 句，各自语气
function missNoteOf(ag, 周号){ … 按周号取句（不摇 rng）… }
// missStep 里：先落"惦记"那条独白，再落这条留言
pushLog(w,{type:'player',sms:'note',agent:ag.id,name:ag.name,text:'给你留了一句：'+话,thought:''});
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 走哪条通道 | **玩家那条往来通道**（`type:'player'` ＋ `sms:'note'`） | 第 75 单刚把往来记录接上，过滤器按 `type==='player'` 取 ⇒ 留言**自动**进那一栏，不必再开一套 UI |
| 什么时候留 | 与"惦记"同一个触发（周日 18:00、这周你零来信、每人每周至多一条） | 两件事同源：他先想起你，才留话 |
| 说什么 | 四类各 2 句，按**周号**取（不摇 rng） | 各人有各人的语气（"店里关东煮换配方了"／"稿子交了"） |
| 回城可见 | 取材表补 `note` 桶：**有人给你留过 N 句话** | 第 26 单那条欠账的另一半 |
| 顺手修 | 生日问候：`ag.flags['cg_'+mate.id]` 记日号 ⇒ **同一天同一个人只问候一次** | 此前一天能被问候四五回（冷却只有 15 分钟），把接话池抽空 ⇒ 第 48 单那条"同日零重复"偶发假红（撞过两次） |

**为什么这次世界指纹也动了**（与第 74 单相反，值得记）：第 74 单只往日志里写"惦记"（**act** 型），
而本单的留言是 **player 型**——导演层那句"有没有戏"的判断（第 58 单修好的那处）**把 player 条目也算作有戏**，
于是"太平淡就下场雨"的计时被推迟，世界轨迹随之分叉。
**这是合理的**（居民主动留话本来就是"有戏"），但它说明一件事：**同是"写一条日志"，落在哪个 type 上，后果不一样**。

## 七 · 已知接受项与盲区（照实登记，不粉饰）

1. **居民只会"留话"，不会等你回**：留言之后没有后续（你回短信他照常答，但那不是针对这条留言的）。
2. **留言仍挂在"惦记"这一个触发上**：别的时候（生日、节日、他做了件大事）不会主动开口。
   要做成"他随时可能开口"就得给居民一套自己的发起规则，属另一单。
3. **一周最多四条**（每人一条），且要"这一周你一条都没来"——存在感仍然很淡。
4. **顺手修的生日问候**改成"一天一人只问候一次"：代价是同一对邻居当天第二次见面不会再提生日（更自然）；
   收益是接话池不会再被抽空（那条闸从此结构性成立）。
