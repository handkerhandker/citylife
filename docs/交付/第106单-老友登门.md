# 第 106 单 · 关系状态机 B 档①「老友会主动登门」（散步顺路去看看他）

> 一句话：第 105 单出的 B 档方案里，① 是"老友之间主动登门"。落地时换了一条**更省**的路：
> **不另开一趟"专程去看他"**（那要多走一段路、班次节律会漂——第 104 单试过、门禁当场拒收），
> 而是**搭傍晚散步那一趟**：先把落点那一下摇完（**摇签次序与次数一字不动**），
> 若有个老友**在别的屋子、醒着、又没在上班**，就把落点从公园／江边改成他那儿；**一周至多一次**。
> 实测：**0.47–0.48 次/天**（187–194 次/400 天，每人约一周一次）、首次发生在 **D38–D42**。
> 版本：v95 → **v96**。指纹：世界 `ca77cce8…` 与门禁 `d759a1f6…` **原样**（登门最早 D38，两枚指纹只看头 30 天），
> SIM 块 md5 `cc3778e3…` → **`1891813e…`**。

## 二 · 为什么改搭散步（坑先写下来）

| 试法 | 结果 |
|---|---|
| **专程走一趟**（方案原稿：`setActivity(…友.anchor…,20,null,…)`） | 位置一变，"哪一程要走路"就跟着变：他回家／上班那几程会各多 10 分钟 ⇒ 班次节律漂、别人的日子跟着变——**第 104 单**（店员理货）就是这么被门禁拒收的，同一族病 |
| **搭散步那一趟**（本单落成） | 散步本来就要出门、本来就要摇那一下落点 ⇒ 把它换成老友那儿，**时长与摇签次序一字不动**，只有"往哪儿走、日志写哪句"变 |

## 三 · 设计

```js
function 老友去处(w, ag){                       // 一处定义；门槛读同一张档位表
  const 线=(REL_TIERS[3]&&REL_TIERS[3].lo)||35;   // 「老友」
  const 周号=Math.floor(w.t/(7*1440));
  if(ag.visitWeek===周号) return null;            // 一周至多一次（照 missWeek／talkWeek 先例）
  for(const o of w.agents){
    if(o===ag) continue;
    if(relGet(ag,o.id)<线 || relGet(o,ag.id)<线) continue;   // 两边都到「老友」（关系是半张表）
    if(roomOf(o.anchor)===roomOf(ag.anchor)) continue;       // 已经同屋 ⇒ 不必"去"
    if(!醒着(o)) continue;                                    // 睡着／小憩 ⇒ 不打扰
    if(o.activity&&o.activity.type==='work') continue;        // 上班 ⇒ 不打扰
    return o;
  }
  return null;
}
// 傍晚散步那一支：**先摇后换**（rng 次序与次数一字不动）
const 掷=w.rng()<0.5?'park_bench':'river_walk';
const 友=老友去处(w,ag);
const spot=友?友.anchor:掷;
if(友) ag.visitWeek=Math.floor(w.t/(7*1440));
setActivity(w,ag,spot,'stroll',友?'串门':'散步',tempoDur(w,ag,40),天气词(…),友?('去看看'+友.name):'出门散步');
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **搭散步那一趟** | 只换落点与两行字 | 时长／忙到几点／后续决策**逐拍不变**（第 104 单的教训） |
| **两边都到「老友」** | 读 `REL_TIERS[3].lo`，不另立门槛 | 关系是半张表（第 88 单口径），"去串门"要两个人都认 |
| **一周至多一次** | `ag.visitWeek`（与 `missWeek`／`talkWeek` 同一套周号） | ★不加这道，实测**每晚的散步都会变成串门**（1.45–1.50 次/天）——江边就没人走了（第 38／39 单的路灯江风、第 97 单那批雨里散步的独白都会落空） |
| **不打扰上班／睡觉的人** | `醒着()` ＋ 排除 `work` | 与第 88 单"上班／吃饭／睡觉一概不碰"同一条红线 |
| **零新增"决定"** | 不新开分支、不改摇签 | 只占**已有的**散步那一档 |
