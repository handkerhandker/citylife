# 第 48 单 · 接话池分组（决策者裁定 C）

> 一句话：**接话不再"万能"，而是答得上**——开口句先归类，接话从**同一类**那一组里取。
> 主判据：3 种子 × 30 天 **552/552 场同类命中 100%**（错位 0、串门 0、同日重复 0）；12 种子扩样 2168 场同样 100%。
> 指纹：**世界指纹与门禁指纹逐字节不变**，只有 SIM 块 md5 变——这正是"纯文案层改动"的正字标记。

## 一 · 缘由（第 37 单取证坐实：约半数对话答非所问）

第 27 单把闲聊拆成「开口池 ＋ 接话池」时，**两句是各抽各的**。那条设计下，接话句必须能接在**任意**开口句之后，
于是 32 条接话**全部**退化成敷衍式承接（同感／不好说／细想也是／经这么一提…），离线实录里约半数对话答非所问：

```
「饭吃了没呀，我这人一天到晚惦记着吃。」 → 「同感。我这边一天下来，只想少花点力气。」
「新机器的钱还在攒，别问进度。」        → 「说起来也是，我总盼着能多认识几个人，热闹点好。」
```

第 27 单交付件第三章口径②已自行预告这个必然后果；第 37 单取证把它变成读数（**32/32 条以承接语起手**），
并给出候选治法：**接话池按开口句的类别分组，配对时按类取**。本单就是这条治法。

**决策依据**：三条世界侧账的推荐顺序是 **C → A → B**；A 已由第 46／47 单做完，本单做 C，B（雨回流进行为）仍挂账。
决策者已给出「不回复就按最推荐的往下做」，故本单不再另请拍板。

## 二 · 调研（同类作品怎么做"接话"，出处已实测）

| 出处 | 查到的做法 | 本单怎么用 |
|---|---|---|
| GDC Vault · Elan Ruskin《Dynamic Dialogue in Left 4 Dead》<br>https://www.gdcvault.com/play/1012216/Dynamic-Dialogue-in-Left<br>（2026-10-03 实测可访问，HTTP 200） | 台词**由情境规则挑**，不是随机播；同一条规则下的台词才答得上 | 「开口归类 → 按类取接话」＝这条规则的最小形态 |
| 中文维基百科·对话树<br>https://zh.wikipedia.org/wiki/對話樹<br>（2026-10-03 实测可访问，HTTP 200） | 对话写成节点树，**每一句回应都挂在上一句下面** | 本单把接话挂到「开口句的类别」上：这层结构的最粗粒度版（不做分支、不做状态机） |

**没查到、故没采信的**：RimWorld 的 `InteractionDef`（一次社交＝发起方＋回应方同属**一条**定义）本来是更好的同型先例，
但 `rimworldwiki.com` 的搜索 API 对该词返回 **0 命中**、相关页面 404——**没拿到可引用的页面，就只当线索记在这里，不当证据**。

**本单不是照搬任何一款游戏的功能**：它修的是第 37 单自己取证出来的缺陷；上面两处只是确认
「接话必须与开口同属一个上下文」在同类作品里是通行做法。

## 三 · 设计（一处定义、缺组回落、容量按实测峰值定）

1. **开口句归类**：新增 `src:const CHAT_KINDS=['eat','busy','invite','vent','view','self'];` 六类，
   与 `src:const CHAT_OPEN_KIND={`（四人 × 十句，与开口池**同序一一对应**）。
   六类口径写到"这一句在干什么"粒度即止：`eat` 在问我吃没吃／`busy` 在问我忙不忙累不累／`invite` 在说某个地方／
   `vent` 在吐苦水／`view` 在说看法／`self` 在说自己。
   **为什么问句要拆成两类**：吃没吃与忙不忙问的是不同的事，一句「我也差不多」哪一类都接不住。
2. **接话池分组**：`CHAT_FB_REPLY` 从「逐人 8 条平铺」改成「逐人 × 类别 各一组」（四人六组共 66 条）。
   每句只保证接得住**本组那一类**开口，故可以真的回应内容。
3. **配对只有一处定义**：`src:function chatKindOf(workKind,said){` 查表（查不到回落 `view`）；
   `src:function chatReplyGroup(workKind,kind){` 取组（缺组回落 `view`，连 `view` 都没有时用他自己的开口池兜底，
   运行时绝不哑掉）。`decide()` 里就是这两句：
   `src:const grp=chatReplyGroup(mate.workKind,chatKindOf(ag.workKind,said));` ＋ `src:const back=pickV(w,grp.arr,mate,grp.key);`
4. **抽签次数一字未改**：每场闲聊仍是「一次开口 ＋ 一次接话」，各消耗 1 次 `rng` ⇒ **rng 流不动、世界行为不变**。
   变的只是后一句从哪一组里抽、以及抽签的号段（键带类别后缀，照「不同数组严禁共键」的既有规矩）。

## 五 · 主判据：改前 ↔ 改后（同一支取证脚本）

**改前**（v49，`tools/world-audit/anchors.cjs` 问三 ＋ 第 37 单取证）：
32 条接话句**全部**以承接语起手；离线实录里约半数对话答非所问；配对无类别可言（一句要接住全部四十句）。

**改后**：

| 读数 | 口径 | 结果 |
|---|---|---|
| 同类命中率 | 3 颗种子 × 30 天，552 场闲聊 | **552 / 552 ＝ 100%**（错位 0） |
| 串门（接话句同时落在别的组） | 同上 | **0 场** |
| 同日重复（同人同日同组抽到同一句） | 同上 | **0 次** |
| 扩样浸泡 | 12 颗种子 × 30 天，**2168 场** | 100% 同类命中 · 错位 0 · 串门 0 · 同日重复 **0** |
| 接话句覆盖面 | probe 全量样本 | **66 / 66 句都被抽到过**（每句都印出了它接过的开口句，见下） |

**逐字实录（改后抽样，同一批种子）**——这就是"答上了"的样子：

```
「饭吃了没呀，我这人一天到晚惦记着吃。」  → 「吃过了。你要是不嫌晚，我给你煮点。」
「吃过了没。空着肚子做判断，容易出错。」  → 「吃了。饿不着的，你放心。」
「忙不忙。我这边一向是这个节奏。」        → 「不算忙。稿子在那儿，急也急不来。」
「周日街市我打算去逛逛，一块儿去呗。」    → 「那地方我常去。你要动身喊我一声。」
「干这行忙起来脚不沾地，哎呀，坐下才觉出累。」 → 「谁也不轻松。熬过去就是了。」
「醒得早是老毛病，一天里大半时候脑子都是钝的。」 → 「我也差不多。安静惯了，人也懒了。」
```

`tools/chat-pair/probe.cjs` 第四节把**每一句接话接过哪些开口**逐行印出来（66 行全印，供目验）；
`tools/world-audit/anchors.cjs` 问三同时印「开口句 → 类别」的归类清单，**40 句逐句可核**。

## 六 · 容量：按 (人 × 类别) 的实测峰值定组容量

第 13 单既有口径：**池容量 ≥ 单日抽取峰值**。分组之后容量要**按组**核，故 `capacity.cjs` 增加一张矩阵
（300 颗种子 × 30 天，补算模式＝AI 缺席那条路，与第 27 单同一套样本口径）：

```
         eat   busy invite   vent   view   self
 接话 顾云帆   2      3      4      3      3      3
 接话 沈小满   2      2      2      2      3      3
 接话 陆知秋   2      2      3      3      3      4
 接话 白一鸣   2      2      3      3      3      4
 容量核对：✔ 每一组都 ≥ 该组实测峰值
```

这张表**当场抓出第一版不够**：第一版每组只写了 2 条，核对报「✘ 8 组不够」（最紧的一组需要 4 条）。
补齐到 66 条之后复核 ✔。**先量后定，不靠手感**。

## 九 · 已知接受项、盲区与"换量尺"的账（照实登记）

1. **类别表贴错标签，机器查不出来（判据级盲区）**：行为断言查的是**接线**——"接话确实出自表说的那一组"；
   它查不出"表本身把某句贴错了类"。两条腿各有一条：机械那条（结构＋接线）在门禁里，
   语义那条只能靠 `probe.cjs` 印出的 40 行归类清单**人眼过一遍**（本单已过，并写进交付件）。
   ——这与第 39 单那笔「锚点自证」同族，故照实登记。
2. **`invite` 类是粗分组**：它同时装着"约我一块去""问我那地方去过没有""让我捎带东西"三种动作，
   故该组接话写成"地点通用"口径。要更细就得再拆类，代价是每组容量更小、重复更容易——**本单刻意停在六类**。
3. **同日零重复不是数学上界**：容量按 300 颗种子的实测峰值定，扩样 12 颗种子 × 30 天零复发；
   真遇到比历史峰值更密的一天，`pickV` 的「池尽重置」会兜底（宁可重复不可沉默），当日会重一句。
4. **换量尺的账（第 27 单那条断言）**：原判据是"离线 3 天 23 场闲聊**逐场不同**"，
   那是按 10×8 平铺池定的口径；分组后每组只有 2–4 条，**跨天**再抽到同一对是可能的（实测 22/23，最高频一对占 8.7%）。
   要防的是"复读机"（改前最高频一组占 **40–60%**），不是"一次都不许重"，故改判两档：
   **① 最高频一对 ≤2 场且占比 <20%；② 不同对 ≥ 场数−1**。三颗种子实测 18/18、22/23、14/14 全过。
   ——换量尺照第 27 单「无话题霸屏」那次的先例办：**先取证、再换尺、写进交付件**。
5. **世界侧还剩 B（雨回流进行为）**未做；本单不碰天气。
