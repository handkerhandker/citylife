## 一 · AI 中转地址（游戏侧，v145）

- 设置页新增一行：**输入框 ＋ 保存 ＋ 清空**；提示语写明"留空＝页面同源 /relay；装进手机 App 后必须填"。
- 规矩写死在一处：`aiRelayURL()`（读）／`aiRelaySet()`（写）——**只认 http/https**（挡 `javascript:`/`data:`），
  末尾**自动补 `/relay`**；空或非法一律回落到同源（绝不因设置写坏就连不上）。
- `rawCallRelay` 的 fetch 从写死的 `'/relay'` 改成 `aiRelayURL()`——**直连与中转两条线仍从唯一入口过**。
- 存 **localStorage**（`citylife-relay-v1`）：这是"这台设备的设置"，**不进存档信封、不进世界**
  （换设备重填即可；SIM 块里零 `aiRelay` 符号 ⇒ 三指纹原样）。
- 通道那一行会显示「中转站（自填地址）」。

## 二 · APK 全屏铺满（壳侧；照交接文档 §3 四层配方）

**病灶**：宿主窗口底色是白的 ＋ 没做 edge-to-edge ⇒ 竖屏上下、横屏三边露白（真机截图实证）。

**治法（四层，缺一不可）**：

1. **两栏不藏、只透明**——文档实测：在卓易通里藏掉状态栏，宿主会用**黑杠**填上，画面反而被切；
2. **内容铺到栏下面**：`setDecorFitsSystemWindows(false)` ＋ 关掉 Android 10+ 的强制对比蒙层
   （`setStatusBarContrastEnforced/​setNavigationBarContrastEnforced(false)`）＋ 挖孔 `shortEdges`；
3. **运行时自己量 insets**（判据＝数值 ＋ `isVisible()` **两条腿**；**横屏强制 top=0**——宿主会谎报
   竖屏的 112px；**物理像素 ÷ density** 换成 CSS px）→ 写进页面的 `--sa-t/-b/-l/-r`
   （游戏那四个变量本来就是给安全区用的，inline 覆盖 `env()`）；旋转后在 `onConfigurationChanged`
   补读 0/400/1200ms（manifest 声明了 configChanges ⇒ 系统不再派发回调）；
4. **上下两条渐隐层**（原生 View，在系统栏同一坐标系里才对得齐）：顶部"底色→透明"带一段实色 guard；
   底部"透明→底色"、下沿贴系统蒙层上沿。渐隐层不挂点击监听 ⇒ 点击照常穿到 WebView。

**产物**：`F:\资料\codex\云港小事\outputs\citylife-debug-v145-immersive.apk`（4.48MB，内含 **v145**）。

**照实登记的边界**（照交接文档 §5.1／§6／§9 口径）：

- 底部手势区那一条（约 48px）**是系统盖的蒙层，应用盖不掉**。若真机上看着仍偏白，下一版把底部渐隐
  改成"同浓度白"（一行改动）——**以目标真机实测为准**；
- 文档 §6 明确"**别把能装当能跑**"：同一个 APK 在不同鸿蒙机型/卓易通版本上表现可能不同；
- 文档 §5.4 提醒：卓易通里有"横屏游戏退出自动重启"的真实（不同工程）案例 ⇒ 建议单独试"边缘返回退游戏"；
- 文档 §5.5：鸿蒙 NEXT 上没有 adb，量帧率只能靠游戏自带 debug 覆盖层（本轮未做，登记为待办）。
