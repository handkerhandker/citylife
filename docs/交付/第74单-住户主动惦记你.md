# 第 74 单 · 住户主动惦记你（一周没来信，他翻出上次那条看两遍）

> 一句话：本作此前的口径是"**收到你短信才有反应**"——你不出声，他们一声不吭。
> 本单补另一半：**一周将尽（周日 18:00）时，若这一周你一条短信都没来**，他会翻出上次那条**看两遍**
> （一条带住户名的个人日志）；回城弹窗的取材表里也因此多了一桶「**有人惦记过你 N 回**」。
> 指纹：**只有 SIM 块 md5 变**（`8ad577ea…` → **`43a742f3…`**），世界 `f23e62ed…` 与门禁 `90242cc8…`
> **逐字节原样**——零 AI、零 rng、只写日志，**不改变任何行为**（不去找你、不扣钱、不改作息）。
> 版本：v71 → **v72**。这正是第 26 单那条未完成的一半：「住户主动惦记你」。

## 一 · 缘由（补上"关系是双向的"那半边）

第 26 单结项时照实登记过：回城痕迹里只接了"你临走前发的那条短信（已读不回）"，
**没有做"住户主动惦记你"**——就是全城只有玩家会开口，居民永远是被动的一方。
调研出处（逐字原文已登记在 `docs/规划/借鉴调研-2026-10-03.md` 第四节）：

| 出处 | 抄到的口径 |
|---|---|
| 星露谷 wiki · Friendship | 「Each day, **not talking to a villager** will slightly decrease their friendship」——**你不出声，关系会退** ⇒ 关系是双向的 |
| Nookipedia · Friendship | 动森的友谊靠「speaking to the villager for the first time each day」累积 ⇒ 反过来，"长期不来"本身也是关系里的一件事 |

## 二 · 设计（零 AI、零 rng、零新素材；只加一条日志）

```js
const MISS={ day:6, at:18*60 };        // 周日 18:00（避开 20:00 的夜谈）
function missStep(w){
  if(PURE.weekday(w.t)!==MISS.day || PURE.minuteOfDay(w.t)!==MISS.at) return;
  const 周号=Math.floor(w.t/(7*1440));
  for(const ag of w.agents){
    if(ag.week && (ag.week.信|0)>0) continue;   // 这周收到过你的短信 ⇒ 不惦记
    if(ag.missWeek===周号) continue;             // 每人每周至多一条
    ag.missWeek=周号;
    logAct(w,ag,'翻到上次的短信，看了两遍','（这周你一句话都没来。）');
  }
}
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 什么时候惦记 | **周日 18:00**（一周将尽；20:00 是夜谈，避开） | 按周结算，与既有的周账同节拍 |
| 什么条件 | `ag.week.信===0`——**这一周**你一条短信都没来 | 用的是**已有**的周账（第 53 单那本），不新造计数器 |
| 落点 | 一条**个人日志**（带住户名） | 它属于"他的这一天"，不是城市播报 |
| 回城可见 | `BACK_SUM` 新开一桶 `miss`：**有人惦记过你 N 回** | 第 26 单那条欠账要的正是"回城能看见" |
| 去重 | `ag.missWeek` 记周号 | 每人每周至多一条（旧档缺字段＝当作没记过） |
| 边界 | **不改变任何行为** | 不去找你、不扣钱、不改作息（这条写进注释） |

## 七 · 已知接受项与盲区（照实登记，不粉饰）

1. **"惦记"目前只有一条动作**：翻出上次的短信看两遍。没有"他主动给你发消息"（本作里短信是单向的），
   也没有"他为此做什么"（不去找你、不改作息）——要那些得先有"居民 → 玩家"的通道，属另一单。
2. **门槛是"这一周一条都没来"**：你只要来一条，全城四个人这一周都不会惦记。粒度是**周**，
   不是"你几天没来"——真要按天算得新起一个"上次来信是哪天"的账（属改结构）。
3. **一周最多四条**（每人一条）。它不会刷屏，反过来说也不显眼：只在回城弹窗与日志里各出现一次。
4. **`miss` 桶的文案是"有人惦记过你 N 回"**——不点名是谁（取材表那套本来就只报数，名字在日志里）。
