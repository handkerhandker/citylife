# 第 121 单 · 玩家篇③期：节日／生日读档位

> 一句话：第 119 单让**日常**回应按档位分了两版，但一年里最重的那两句——**生日的回信**与
> **生日／灯节夜给你留的那句**——仍与关系无关：把一个人处熟之后，他说的还和陌生人一样。
> 本单把这两处接上关系（门槛沿用同一张档位表的「熟」档，**缺键回落**原表／原池）。
> **只换池、不换事**：不新增抽签、不动行为 ⇒ **跨版本逐拍全同**、世界与门禁指纹原样。
> 版本 v107 → **v108**。
