# 第 183 单 · 手机返回键（壳先问页面：关弹窗 → 回现场页 → 才真退）——v148 → **v149**

> 一句话：安卓壳拿到系统返回键后**先问页面一句"这一按你能消化吗"**——打开的弹窗先关、
> 不在现场页先回现场页；页面说消化不了，壳才真退 App。次序与页面里既有的
> `Input.on('back', …)`（键盘/手柄走那条）**同一套**，不另立第二套判据。

## 一 · 改了什么

1. **页面**（`city-life-framework.html`）：新增 `window.__back()`——
   ① 弹窗开着 → `closeDialog()` 并返回 `true`；② 不在现场页 → `setScreen('live')` 并返回 `true`；
   ③ 都消化不了 → 返回 `false`（＝壳照常退出，**不吞返回键**）。
2. **壳**（`apk/android/.../MainActivity.java`）：覆写 `onBackPressed()`——
   `evaluateJavascript` 问一次 `window.__back()`，回答不是 1 才调 `真退出()`（`super.onBackPressed()`）。
