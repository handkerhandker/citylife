# 第 153 单 · "单帧脉冲"溯源结案（工具层，不涨号·仍 v126）

> 一句话：把一直缠着烟花探针的"一帧差异"查清了——**页面加载后约 2.2 秒的一次布局微调**
> （live-wrap 高度 −0.55px → ResizeObserver → 画布高度 −1px、view.oy −0.27px → 整屏平移一帧），
> 外加"首次 getImageData 读回"的候选效应；一帧即散、用户不可见。处置：探针"等稳"把
> **画布尺寸**纳入看门、阈值收紧（0.5→0.1px）、放行后再等 1.5 秒；"大差帧数"判据保留作双保险。

## 一 · 现象与溯源

1. 现象（第 148/149 单取证时发现）：画布存在**一帧即散**的整屏微变（dd 6–24 口径下
   江面带 ~5858 像素），**相对"探针采样起点"固定出现在第 2 帧**，改前无烟花版同样有——
   它逼着烟花探针改用"大差帧数"判据绕行。
2. 溯源（rAF 逐帧记录 `view.s/ox/oy + 画布尺寸 + live-wrap 尺寸` 共 400 帧）：

   ```
   #0  全量稳定（记录起点）
   #1 (+2ms)  bh: 726.61 → 726.06      ← live-wrap 高度少 0.55px（布局微调）
   #2 (+10ms) oy: 105.621 → 105.348    ← ResizeObserver → resizeCanvas 重算
              ch: 727 → 726                （画布高度 −1px、纵向偏移 −0.27px）
   #3..#399   全部无变化（6.4 秒稳定）
   ```

   ⇒ 脉冲 = **"布局微调的一帧"**（1px 级整屏平移在 dd 6–24 口径下放大成 ~5858 像素差）。
   另一候选（未逐帧定罪、如实登记）：第一次 `getImageData` 读回可能改变合成路径，
   使"采样第 2 帧"必然出现一次差异。

## 二 · 处置（只动探针与注释，无产品改动）

| 件 | 做法 |
|---|---|
| `tools/firework-audit/probe.mjs` 等稳 | 监视量加上 **cv.width/height**；布局盒阈值 0.5→**0.1px**；放行后再等 **1.5 秒** |
| 判据 | "大差帧数"保留（脉冲最多贡献 1 帧、真烟花 8 帧——已实证足够区分） |
| 注释 | 把脉冲的溯源结论写进探针头（后人不必再查） |
