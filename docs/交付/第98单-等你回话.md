# 第 98 单 · 居民会等你回话

> 一句话：第 76／77 单让居民会主动留话，可登记里写着「**他只会'留话'，不会等你回**」。
> 本单让那句话说完整：他留了话就**记一笔等待**（`ag.waiting`），短信页的往来记录顶上一行
> 「**TA 留了话，在等你回一句。**」；你发一条短信过去，他的回复里就多一句「（等了两天，总算等到了。）」
> 并且等待撤掉；**过了两天还没回音，他就不等了**（那行自己消失，不叨叨）。
> 版本：v90 → **v91**。指纹：世界 `b5935386…` 与门禁 `d759a1f6…` **原样**，SIM 块 md5 `3294f472…` → **`898e81b6…`**。

## 一 · 缘由

`待办.md` 第 76／77 单那两条登记：

> ① 他只会"留话"，**不会等你回**；
> ④ 居民仍不会**等你回**。

## 二 · 设计

```js
// 留话那两处（惦记 ／ 别的时候也开口）各记一笔：
ag.waiting={ t:w.t, line:话 };        // 新的这句顶掉旧的那笔（等的是最新那一句）
// 每天 21:00（noteStep 本来每天都跑）扫一遍过期：
if(x.waiting && w.t-x.waiting.t>2*1440) delete x.waiting;
// 你发短信 ⇒ 他读信那一刻：
const 等他=!!(ag.waiting&&isFinite(ag.waiting.t)); if(等他) delete ag.waiting;
…thought: 原来的反应 + (等他?'（等了两天，总算等到了。）':'')
// 往来记录（每人一栏）顶上：
等 ? '<li class="faint ph-wait">TA 留了话，在等你回一句。</li>' : ''
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **等待记在人身上** | `ag.waiting={t,line}` | 一栏一处；旧档没有这个字段＝没在等（不判坏档） |
| **两天就不等** | 每天 21:00 扫一遍，`>2*1440` 撤掉 | "等过"是心意，"等到天荒地老"是负担；两天够玩家看见那行提示 |
| **回话有专属回应** | 回复的 `thought` 末尾补一句 | **不加条目、不改 type** ⇒ 未读角标不虚增、"有戏"与下雨时机一字不动 |
| **只在还在等时显示** | 那行跟着**当前状态**走，不是历史条目 | 他回了话/等过期，那行自己消失；也不进日志墙（不占额度） |

## 七 · 已知接受项

1. **只等最新那一句**：等待期间若又留了新话，等的是新的那句（旧的自动作废）。
2. **两天是拍的**：`2*1440` 分钟（`noteStep` 里一处）；要改就改这一个数。
3. **等待中他照样会留新话**：本单**不抑制**新留言——那会改动"有戏"的拍数、世界指纹要跟着变；
   "等着，但日子照过"也是本作的口径。
4. **没有"生气"分支**：等不到就只是不等了，不掉关系、不留一句抱怨（关系值只记住户之间，玩家不在网里——第 88 单口径）。
