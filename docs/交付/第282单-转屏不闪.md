# 第 282 单 · 转屏闪帧修复：竖→横第一帧不再错位（"左侧被工具栏截断"那一下）—— v210 → v211

> 一句话：你 2026-10-06 报的"**竖屏切横屏先闪一帧、左侧被工具栏截断、零点几秒后才跳正**"——
> 根因是**内衬缓存**：第 244 单立的 `可视区()`（左右栏量出来的内衬）只在**每秒兜底**重测一次，
> 转屏那一刻缓存里左栏宽还是竖屏量出的 **0** ⇒ 这一帧的相机夹取按"**没有左栏**"算，地图左缘压到 0、
> 被工具栏盖住（＝你的图一）；等下一次兜底重测（最多 1 秒后）才跳正（＝你的图二）。
> 治法＝**任何一次尺寸/布局变化（`resizeCanvas()` 必经）都就地作废缓存** ⇒ 下一帧现读新几何。

## 一 · 改了哪一行

- `city-life-framework.html`：`resizeCanvas()` 末尾加一句 **`内衬上次=0;`**（＋一段缘由注释：转屏第一帧
  为什么必须重测）；版本 v210 → **v211**。
- `harness.js`：第 282 单块——结构（那句**恰一处**）＋反向自查（抠掉 ⇒ 判红）。
- `tools/touch-audit/probe.mjs`：新增 **⑩**（转屏第一帧判据：先把内衬缓存**刷到"刚刚"**＝真实转屏
  前一刻的现场 → 转屏 → 镜头顶到世界左上角 → 下一帧读 `ox/oy`）＋给探针加 `量内衬` 读数口。
