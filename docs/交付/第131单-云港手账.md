# 第 131 单 · 云港手账（玩家侧里程碑）——版本 v113 → **v114**

> 一句话：住户有目标（第 52／53 单）、关系有档位，但**玩家自己**没有一个"我做到过什么"的清单。
> 本单加一张「云港手账」（角色页、与日历同排）：十条里程碑——看过一星期／发过第一条短信／收到第一封回音／
> 收到第一句留言／在他生日那天说声快乐／和一个人处到「熟」／处到「老友」／赶上第一场江灯节／
> 发满 100 条短信／看过一整年；小账存在**存档信封**里（不碰世界），按日志 lid 水位增量扫（**重载不重复计**）。

## 二 · 口径

| 项 | 内容 |
|---|---|
| 小账 | `state.miles={sms,replies,notes,bdays,countedLid}`，随 `saveMeta()` 走；旧档从 0 起算 |
| 为什么旧档不追溯 | 可见日志只留 400 条——追溯出来的数会随日志被挤掉而**倒退**，不如从本版起算干净 |
| 计数 | 只看日志：`out`→sms；`reply`／`noreply`→replies（**"已读不回"也算回音**——没有中转站时它是常态）；`note`→notes；生日那天的 `out`→bdays |
| 不重复 | 按 `lid` 水位增量扫；重载后水位续上（探针里验的就是"刷新不翻倍"） |
| 世界 | **一字未动**（纯 DOM＋存档信封）；三个指纹原样 |
