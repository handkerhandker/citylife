## 二 · 设计

```js
const REL={ cap:60, bump:1, bdayBump:3, coldAfter:3, coldLose:1, coldLine:5 };
const REL_TIERS=[{name:'生疏',lo:0},{name:'点头之交',lo:10},{name:'熟',lo:20},{name:'老友',lo:35},{name:'家人一样',lo:50}];
ag.rel = { 对方id:{ v:38, day:412 } }        // 只存"他视角"的半张表；day＝最后一次当面说话的日号
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **涨** | 每天第一次当面说话 `+1`；生日那天那句问候 `+3` | 动森"每天第一次才算"防刷；问候是**说话人**做的动作，故 `+3` 只记在**说话人→寿星**那一半 |
| **落** | 连着 3 天没说话 ⇒ 第 4 天起每天 `−1` | 星露谷那条"不打招呼就掉" |
| **停** | 掉到**本档下限**就停（生疏 0／点头之交 10／熟 20／老友 35／家人一样 50） | 星露谷"到档位停"；也守住"不夺走"——关系**不会降档** |
| **冷线** | 连着 **5 天**没说话留一条（每人每条关系只留一次） | 剪辑层要有"凉下来"这种弱信号，但不天天刷 |
| **旧档** | 缺 `ag.rel` 一律**就地补 0**（`relV` 把坏值归一到 0–60） | 照 `goalOf`／`rhyRest` 那套：宁可缺省也不判坏档 |
| **半张表** | 两半各存一份、各按自己的 `day` 涨落 | 方向差**从生日那天长出来**（说话人 +3／寿星 +1） |
| **三处外显** | ① 角色卡与角色详情那一行改读关系值（挑人仍按"和谁聊得最多"）；② 剪辑层 `rel_up`（甲 1.6）／`rel_cold`（乙 0.8）；③ 周记忆加"（其中和 X 说了 N 回）" | 只加显示与上卡，**不加行为** |
| **一处定义** | 档位表、四个旋钮、两句日志前缀（`关系：`）都只有一处；门禁按真值读 | 治"闸自己硬编码旧写法"那族错 |
