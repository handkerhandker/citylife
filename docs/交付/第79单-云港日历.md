# 第 79 单 · 云港日历（把"接下来会发生什么"摆出来）

> 一句话：本作这几年把日程越挂越多（周五夜市／周日街市／周日 20:00 夜谈／每月 2 号交租／
> 四人各一个生日／一年一次的江灯节），可**玩家只能靠记性**——公告散在晨报与播报里。
> 本单在**角色页头顶**加一张只读清单：**接下来七天**每天有什么 ＋ **江灯节倒计时** ＋ **下一个生日**。
> 数据全部来自既有表 ⇒ **零新增世界状态、零 rng、零写操作**；**三个指纹全部原样**，只有界面涨号 v75 → **v76**。

## 一 · 缘由与出处

出处（2026-10-03 实测可访问）：星露谷 wiki 的 Festivals／Birthdays 条目里，村民的生日与节日**都挂在日历上**，
玩家靠"看日历"安排；Nookipedia·Event 同理（动森的公告栏提前贴出活动、当天再公告一次）。
本作第 56–77 单陆续把"日程"这一层做厚了，却一直**缺一页把这些日程集中说出来**的地方——
本单补的正是这一页。

## 二 · 设计（纯 DOM 层，一处取词）

```js
function calLines(w, 天){            // 只读：给它一个世界，回一串现成的行
  for(未来 n 天){
    周五 → '19:00 夜市', '18:00 发薪'
    周日 → '白天街市', '20:00 夜谈角'
    每月 2 号 → '交租日'
    江灯节当天 → '19:00 江灯节（江边）'
    谁生日 → '<名字>生日'
  }
  末尾两行：'江灯节：X 天后（D?）' ／ '下一个生日：<名字>（X 天后）'
}
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 摆在哪 | 角色页**头顶**一张整宽卡片（`#cal-card`／`#cal-list`） | 不挤角色卡网格、不动画布尺寸（两种视口都安全） |
| 数据源 | 全部既有：`NIGHT_MKT`／`TALK`／`BIRTHDAYS`／`FESTIVAL`／`day%30` | **不新增状态**，也不新造一份日程表 |
| 刷新 | 与角色卡同一处（`renderRoles`） | 切到角色页即最新 |
| 措辞 | 今天标"今天"、明天标"明天"，其余留空 | 一眼看出远近 |

## 七 · 已知接受项与盲区（照实登记，不粉饰）

1. **只列七天 ＋ 两件远景**：再远的日程（下个月的生日、明年的江灯节）不展开；要拉长就改 `calLines` 那个天数。
2. **不列"周日 18:00 的惦记"**：那是"你一周没来信"才会发生的事，写进日历会像是固定日程（会误导）。
3. **没有"点击跳到那天"**：这只是一张清单，不能点。要做成可点（跳到某天/筛某人）属另一单。
4. **日历用的是"世界日"**（D1 起算），不是现实日期——本作的日历本来就是自造的 12×30。
