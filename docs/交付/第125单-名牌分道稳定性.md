# 第 125 单 · 名牌分道的稳定性（决策者实报："名字和想的事情说的话老是上下跳"）

> 一句话：头顶那块名牌，以及摞在它上面的**活动牌**和"**此刻在想**"气泡，会时不时上下跳——实测根因是
> **分道按绘制顺序抢道**（画人的顺序是深度序 `ents.sort((a,b)=>a.fy-b.fy)`，两个人 y 一交叉、道号就互换；
> 挨得近时还会在阈值上来回抖）。本单把分道改成"**先算后画**（按人名 a1→a4 固定顺序贪心着色）
> ＋成对 3px 迟滞 ＋ 逐人黏性/缓降 ＋ 浮道限速步进"，并把两处写死旧写法的断言改成新管线。
> **纯 DOM 层**：三个指纹全原样；版本 v110 → **v111**。

## 一 · 取证（改前）

| 项 | 读数（真浏览器 8 秒 × 160 帧，每 50ms 一采） |
|---|---|
| 与"按名单顺序算出来的道"不一致 | **199–232 / 640 人-帧**（说明道号被绘制顺序带着乱换） |
| 每 50ms 最大视觉位移 | **2.000 道**（不是"抬一道"，有一帧直接跨两道） |
| 位移 >0.5 道的样本 | **19 个**（＝"咔"地跳） |
| 同层重叠违规 | 0（旧写法能防重叠——问题不在重叠，在**乱换道**） |
| 站定时牌子锚点 y 跳变 | 0（跳的是分道，不是人） |

根因（代码）：`nameChip()` 在绘制时按 `nameChipBoxes`（逐人 push）抢道；而 `ents` 是**深度序**。

## 二 · 改法（四道保险）

| 层 | 做法 |
|---|---|
| 先算后画 | `draw()` 里 `本帧道=分名牌道(...)`——按人名固定顺序贪心着色，**与绘制顺序无关** |
| 成对迟滞 | 3px：成形要 `<T−3`、拆开要 `<T+3`（阈值上来回抖不再翻脸） |
| 逐人黏性＋缓降 | 能往下降时先等 **1.2 秒**"确实没人挨着"再落一道（别人那边的变化不再连累你） |
| 浮道限速步进 | **6 道/秒、每帧 ≤0.25 道**——60/120/30fps 与卡帧三种情形都不瞬移 |
