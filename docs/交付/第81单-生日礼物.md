# 第 81 单 · 生日礼物（住户之间：把道贺从"一句话"变成"带点东西"）

> 一句话：第 65 单让邻居**开口**道贺，本单让他**带点东西过来**——生日当天 15:00–21:00，
> 若寿星与他正待在同一间屋，就当面递上一小盒点心（**花自己的钱 −¥8**，每人每年至多一次）。
> 两条日志（送的人"带了…"／收的人"收下了…"）＋ 剪辑层乙级 1.2 一项（摘原文引送的那句）。
> 指纹：**只有 SIM 块 md5 变**（`34bc6177…` → **`aa6fbd84…`**），世界 `b5935386…` 与门禁 `d759a1f6…` **逐字节原样**
> （礼物只发生在生日当天，而 30 天窗口走不到生日）。版本：v77 → **v78**。

## 一 · 缘由与出处

第 65 单交付时登记过："**没做寿星请客/互赠**"。同类作品里，生日从来不只是"说一句"：

| 出处 | 抄到的口径 |
|---|---|
| 星露谷 wiki·Friendship | 「villagers are more likely to **send gifts** in the mail」——关系深了会寄东西 |
| Nookipedia·Birthday | 村民会为寿星**张罗**（蛋糕、礼物那套） |

## 二 · 设计

```js
const GIFT={ cost:8, open:15*60, close:21*60, thing:'一小盒点心' };
// decide() 空闲段（排在夜市之前：一年一次 > 每周一次）：
if(窗口内 && ag.giftYear!==年){
  const 寿星 = 别人(在过生日 && 同屋 && 空闲/散步);
  if(寿星){ ag.giftYear=年; ag.money-=8;
            logAct(送的人,'带了…过去给'+寿星名字,…); logAct(寿星,'收下了…',…); return; }
}
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **当面** | 要求两人 `roomOf(...)` 相同 | "带了东西"得真见到人（不凭空投递） |
| 一年一次 | `ag.giftYear` 记年号（照 `bdayYear` 先例） | 不刷礼、不制造假的热情 |
| 花自己的钱 | −¥8（第 81 单新表 `GIFT.cost`） | 有经济后果才算"事"（与夜市/蛋糕同一口径） |
| 日志前缀 | 送的人那句写成"**带了**…过去给‹名字›" | 归类表按**前缀**匹配；写成"给‹名字›带了…"的话前缀会随名字变 |
| 上卡 | 剪辑层乙级 **1.2** ＋ 摘原文引送的那句 | 与 `mkt_go`／`talk_go` 同一套事件通道 |

## 七 · 已知接受项与盲区（照实登记，不粉饰）

1. **"同屋"是硬条件**：寿星整天在外面，礼物就送不出去（实测四人都摁在客厅才送成）——这是"当面"
   的代价，登记为接受项；要改成"留在家门口"就得另开一条"投递"通道。
2. **礼物只有"一小盒点心"一种**：没有偏好、没有"谁送得更用心"（那要先有关系数值，属关系状态机那单）。
3. **送过礼不会有回礼**：寿星收下就完了（回礼属另一单）。
4. **一次构造里三人花了 ¥8／¥16**：差额是因为有人在窗口里先花了别的钱（吃饭等），**礼物那笔一律 ¥8**。
