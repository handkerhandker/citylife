# 第 99 单 · "他此刻在想什么"看得见（那些独白以前没人读）

> 一句话：查出来一个"画了却没人去"的老账——`setActivity` 的 `thought` **只在 `logText` 不为 null 时才用得上**，
> 而"在家待着"那一支 `logText` 恒为 null ⇒ **`IDLE_THOUGHTS` 那 16 条独白（第 97 单又添了 8 条雨天的）一条都没人读**。
> 本单把它挂到活动上（`ag.activity.think`），并在**角色详情**加一行「**此刻**」：
> 不进日志墙、不占额度、不摇 rng。版本：v91 → **v92**。
> 指纹：世界 `b5935386…` 与门禁 `d759a1f6…` **原样**，SIM 块 md5 `898e81b6…` → **`399048f9…`**。

## 一 · 病根（先量后改）

| 事实 | 证据 |
|---|---|
| `IDLE_THOUGHTS` 有 16 条、`RAIN_IDLE_THOUGHTS` 有 8 条 | 源码两处常量 |
| 它们的调用点是 `setActivity(…, 天气词(w,IDLE_THOUGHTS,…), null)`，最后那个 `null` 就是 `logText` | 源码逐字 |
| `setActivity` 里那句 thought **只喂给 `logAct`**，而 `logText===null` 时整条 `logAct` 不执行 | 源码逐字 |
| ⇒ 这两池字**没有第二个读者**（第 13 单注释里写着"其调用点 logText 恒为 null、独白不上墙，故允许池尽重置"） | 该注释 |

也就是说：**那 24 条独白是死字**——写了、抽了、丢了。第 97 单那句"窗内看雨"同样落在这一支里（它写在雨池里，
但一样没人看得见），这一单把它一并救活。

## 二 · 设计

```js
// setActivity：把独白挂到活动上（以前只喂给日志）
ag.activity={type,label,think:(typeof thought==='string'&&thought)?thought:''};
// 角色详情：有独白才出那一行
+(ag.activity&&ag.activity.think?'<div class="kv"><span>此刻</span><span>「'+esc(ag.activity.think)+'」</span></div>':'')
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **挂在活动上** | `ag.activity.think` | 活动本来就有 `label`，再加半句独白是最轻的落点 |
| **不上墙** | 仍然 `logText=null` | 空闲一拍一条的话日志墙会被灌满（第 13 单那条容量口径就是为此立的） |
| **不摇 rng** | 抽签那一行一字未动 | 只多存一个字段 ⇒ 世界指纹原样 |
| **没有就不显示** | 那一行是条件的 | 睡觉、走路、交心这些没有独白的活动不出这一行，不做样子 |
