# 第 47 单 · 周末去处层（决策者裁定 A 的后半）

> 一句话：**周六不再只是「上班时段短一点」**——白天会有人出门逛，傍晚散步的也更多。
> 主判据（56 天 × 3 种子）：周六「在外」**8.14% → 12.02%**，周末 vs 工作日「在外」**+30.8% → +56.5%**。

## 一 · 缘由（决策者裁定 A 的后半）

第 46 单把「星期」接进了**上班时段**（`src:const WEEK_RULES=` 一张表 ＋ `src:function workWindow(w, ag){` 一处算），
但**没改「做什么」**：周六只是下班早一点，人照样在家／在店里；周末的去处仍然只有周日那一支「周日街市」独享。
第 46 单交付件的「接受项」第一条、`交接说明.md` 第 46 单条都把这笔账挂着：**「周六的去处层没做」**。

本单补的就是这一层。**决策依据**：决策者已裁定 A（让星期进入世界，「2A」）；按现行目标「不回复就按最推荐的往下做」，
A 的后半属同一裁定的自然延伸，故接着做完，不另请拍板。

## 二 · 设计（一张表，只在「没别的事可做」那一段起作用）

去处层与新落成的 `WEEKEND_OUT` 与 `WEEK_RULES` **同一常量区**（SIM 块 `/*WEEK-START*/…/*WEEK-END*/`），
**改周末的样子只改这一张表**：

| 键 | 值 | 含义 |
|---|---|---|
| `dayOut` | `0.35` | 周六白天 10:00–17:00 出门逛的概率 |
| `daySpots` | `['park_bench','river_walk','market']` | 出门去哪：公园长椅／江边步道／广场街市，**等概率三选一** |
| `eveStroll` | `0.45` | 傍晚 18:30–21:00 出门散步的概率（工作日 0.3 不动） |

三条口径（都写进了源码注释）：

1. **工作日够不着这一支**：新分支的前置就是 `src:if(周末 && !sunday && mod>=10*60 && mod<17*60 && w.rng()<WEEKEND_OUT.dayOut){`，
   周一到周五连判据都进不去；`dayOut` 只是「周六那一档的概率」。
2. **周日让给「周日街市」**：`!sunday` 是刻意的——摊位牌上写着周日街市，那是世界里已有的事实，两支**不叠加**。
3. **去处独立掷一次**：`src:const spot=spots[Math.floor(w.rng()*spots.length)%spots.length];`——
   去处表全站只取用一处（门禁按出现次数钉住，多一处就是第二套去处表）。

## 七 · 走位三铁律抓到一条判红 —— **是闸自己的尺子错，不是世界错**

**症状**：`node walkgate.js` 判红一条。

```
FAIL: 避实体改线造的航点全部落在房间内（零穿墙；越界 1 处 [21,22]）
```

这条断言的原意是抓**穿墙**：避实体改线造的格心航点若落到房间外，就是穿墙。
第 47 单把周末去处接进世界后，第一次跑就红了——**先例证、后判断**（判据里现加了一条自我说明输出）：

```
例：a2 @8000 从(28.0,5.5 store) 人此刻在(28.0,5.7 store) 走线终点(21.5,22 室外) 经 (21.5,22)
```

**根因（闸的尺子错，不是世界错）**：这条判据第一版把「走线终点」取成了 `v.x/v.y`＝**人此刻站的地方**，
而走线的真终点是**末航点**（`buildPathRaw` 的 `target`＝站位本身）。例证里 a2 是便利店（store）的人，
正要去广场的街市——**走线重建的那一瞬间，人还站在店里**，于是「店内 → 广场」这条合法的周末出门路线
被判成了「室内 → 室内」的活儿，广场里的航点自然「跑出房间」。

**修法（落在源头，不在症状处打补丁）**：

1. 判据抽成**唯一一处定义** `offRoomHit(起室内,终室内,p)`，实测与反向自查共用同一份，免得闸里两套口径各说各话；
2. 「终点」改取**末航点**（走线终点），起点取**人所在处**；
3. 判据本身**一字未松**：两端都在室内时，改线航点仍必须落在房间里。

**三条反向自查（一条恒绿的闸等于没立）**：

| 自查 | 期望 | 实测 |
|---|---|---|
| 两端都在室内的走线把航点甩到广场 `(21.5,22)` | 判越界 | ✓ 判红（第 47 单第一版正是这么红的） |
| 同一格落在「店内 → 广场」的周末出门路线里 | 放行 | ✓ 不误伤 |
| 门点／街心点（`y` 非整数，非改线造的格心） | 不管辖 | ✓ 不越权 |

改后 `走位三铁律 ALL PASS`（483840 人帧采样、逐帧位移上限、零穿实体、显示位单一来源全绿）。

**本节第二笔账（我自己犯的错，同族第八次）**：例证第一版把起点坐标打成 `rid(ax,ay)`，
而 `ax/ay` 在循环里已经被逐段航点推进覆盖过了——于是印出 `从(28.0,5.5 室外)` 这种**自相矛盾**的读数
（坐标取的是重建前的、房间名取的是推进后的）。修法是**起点坐标另存 `sx0/sy0`**，让同一行里的两个数**同源**。
同族前七次的判据是同一句话：**量之前先确认「我量的」真的是「我要量的那一块」**。
