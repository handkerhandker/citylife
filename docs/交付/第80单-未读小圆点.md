# 第 80 单 · 未读小圆点（"有新回音／留言"要看得出来）

> 一句话：第 75 单把往来记录接上了、第 76／77 单让居民也会留话——可**新回音不会提示你**
> （那条当时就登记成欠账）。本单补一个角标：**水位之后**的"来的"条目 >0 就在「短信」页签上点一个小圆点，
> 进那一页即清零。水位 `state.phSeen` 属"界面读到哪了"，**不进世界状态**、随**存档信封**走。
> 指纹：**三个数全部原样**（纯 DOM 层 ＋ 存档信封多一个字段），只有界面涨号 v76 → **v77**。

## 一 · 缘由（补掉第 75 单登记的那条）

第 75 单交付时写着"**没做未读标记**：新回音不会提示你"；第 76／77 单又让居民开始主动留话，
于是这条更显眼：**他给你留了话，你却得自己想起来去翻。**

## 二 · 设计

```js
state.phSeen                       // 水位：读到哪一条日志了（随存档信封走：saveMeta 写、引导读）
function 未读条数(w, 水位){         // 只数**来的**：read／noreply／note；不数自己发出去的 out
  … 倒着扫 w.log，e.type==='player' && e.lid>水位 && (e.sms==='read'||'noreply'||'note') …
}
function refreshUnread(){ … 变了才碰 DOM；n>9 显示 '9+' … }     // 主循环里刷
setScreen('phone') → state.phSeen = world.lidSeq               // 进这一页即算读过
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 只数"来的" | `read`（TA 读了）／`noreply`（已读不回）／`note`（TA 留话） | 自己刚发出去就给自己点红点，那是噪声 |
| 水位存哪 | **存档信封**（`saveMeta()` ＋ 引导读取），不进 `state.world` | "读到哪了"是界面的账，不该污染世界状态 |
| 角标位置 | 「短信」页签右上角一个小圆点（`#tab-dot`），`n>9` 显示 `9+` | 不占按钮尺寸（照第 31 单"另起一行画"那条口径） |
| 什么时候刷 | 主循环里每拍一次（变了才碰 DOM） | 与既有的刷新节拍一致 |

## 八 · 已知接受项与盲区（照实登记，不粉饰）

1. **只提示"短信"这一类**：剪辑页有卡、日志有大事，都没有角标（要不要给它们也加，属另一单）。
2. **水位是"最后一条"而不是"已读明细"**：进过一次短信页就把**所有**居民的往来都算读过；
   分人未读（"小满有 2 条、云帆有 1 条"）没做。
3. **角标只到 `9+`**：再多也显示 9+。
4. **清档/换档会把水位带走**：它随存档信封走，重开新城自然从 0 起（这是对的）。
