# 第 111 单 · 四季（氛围一期：把"一年里的第几季"画到画面上）

> 一句话：日历这把尺已经在世界里走了四步（**周 → 日 → 年（第 62 单江灯节）→ 个人年（第 64 单生日）**），
> 可**画面上一年到头一个色**——春天和深冬、盛夏与初秋，逐像素相同。本单补上最后一层氛围：**四季罩层**
> （**春＝不着色**／夏＝暖亮／秋＝琥珀／冬＝冷灰蓝），一季 90 天、按整段切（切换落在午夜，被夜色吃掉）。
> **纯显示层**：一张表＋两个纯函数＋`draw()` 里一处调用；**零 rng、零 `w.` 读、世界行为一只像素都没动**
> ⇒ **世界指纹／门禁指纹／SIM 块 md5 三个全原样**（SIM 块一个字节没碰）。版本 v98 → **v99**。

## 一 · 为什么是"氛围一期"（出处与先例）

| 依据 | 原文／纪要 |
|---|---|
| 星露谷／动森 | 季节是这类作品**最显眼**的那把尺（一到季节，整个世界换一套颜色与天气）。本项目调研文件里"天黑时刻随季节漂移"那条候选写着 **"需要先有「季节」这个概念"**（`docs/规划/借鉴调研-2026-10-03.md` 第 46／89 行） |
| 第 62 单·江灯节 | 该单登记的接受项原文：**"要真季节得先改日历正本"**——本单就是那把尺的第一块（日历不动：12 个月 ×30 天＝360 天，四季＝每季 90 天，**从既有日历推出来、不新起一本账**） |
| 本项目老规矩 | **先视觉、后行为**：雨先壁纸（第 23 单）后行为（第 49 单）；天色先罩层（第 33 单）后点灯（第 35 单）；夜市一期二期同理。**本单只做氛围，行为留给二期**（"夏天更常出门／冬天更宅"那一档） |

## 二 · 口径（做什么、不做什么）

| 项 | 口径 |
|---|---|
| 分季 | 春＝D1–90／夏＝D91–180／秋＝D181–270／冬＝D271–360（`SEASON_DAYS=90`，与 `FESTIVAL.yearDays=360` 同一本日历） |
| 色罩 | 春 `a=0.000`（**不着色＝基线**）／夏 `rgba(255,216,138,0.055)`／秋 `rgba(226,150,70,0.080)`／冬 `rgba(176,200,224,0.075)` |
| 上限 | `SEASON_MAX_ALPHA=0.10`（与天色罩层叠加也不压垮名牌文字与选中金框的对比度——第 32／33 单那条口径） |
| 切换 | **整段切**（第 90／180／270 天换季）——那一刻天色罩层本来就在最暗档，突变被夜色吃掉（同类作品也是"睡一觉醒来换季"） |
| 层次 | 画在**天色之下**：夜色、灯与路灯光斑都压在它上面（`draw()` 里 `seasonPaint(` 紧挨在 `skyPaint(` 之前） |
| 不做 | 不碰世界（不掷骰子、不读 `w.`——只吃传进来的 `w.t` 这个数）；**不改任何行为**；不新增播报／剪辑项；不动素材与 UI 其它层 |

## 七 · 已知接受项

1. **春＝不着色**是刻意的：头 90 天与改前逐像素相同（改动射程最小、判据最硬）；代价是"春天没有专属色"。
2. **整段切换**（不插值）：换季那一刻画面会整屏换一档——落在午夜、被夜色吃掉；要"渐变过渡"得另立单。
3. **四季只是氛围**：还没有"夏天更常出门／冬天更宅"那一层（行为二期）。
4. **色值都是拍的**（0.055／0.080／0.075）：由决策者目验定夺，要调只改 `SEASON_KEYS` 一处。
5. **不限季节的素材**（树叶、雪、夏蝉声…）一律没做——那要动素材流水线，另立单。
