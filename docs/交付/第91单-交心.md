# 第 91 单 · 交心（关系涨到「老友」之后，两个人坐下来好好聊一回）

> 一句话：第 88 单给了这四个人一个**会涨会落的关系值**，可它当时**只显示、不上手**；
> 本单给它第一个**回报**——照星露谷那套 `heart events`：一对人**两边都到「老友」（≥35）**、又刚好同屋且空闲时，
> 会**专门发生一场**（坐下聊 90 分钟、两条日志、剪辑层甲级一张），**一对人只发生一次**。
> 零新增世界状态（旗子借用既有的关系条目 `ag.rel[对方].heart`）、**不掷骰子**（到了就发生）。
> 指纹：**只有 SIM 块 md5 变**（`212f0607…` → **`c583763e…`**），世界 `b5935386…` 与门禁 `d759a1f6…`
> **逐字节原样**——因为交心最早发生在 **D36**，两枚指纹只看头 30 天（真证据是长跑探针，见第三节）。版本：v84 → **v85**。

## 一 · 缘由与出处

出处（**本单复核：2026-10-03 实测 HTTP 200**，整句逐字摘）：

> 星露谷 wiki·Friendship（https://stardewvalleywiki.com/Friendship）
> 「As friendships deepen, the villagers' dialogue lines become more friendly, **cut-scenes called heart events occur**,
> villagers are more likely to send gifts in the mail, and marriage is possible with one of the datable villagers.」

第 68 单的方案里，A 档的定位是"**只多记一个数**"；A 档交付时登记的仍是"关系不进任何判据"。
本单做的是**A 档与 B 档之间的那半步**：关系不改变**取舍**（谁去哪里、干什么，一个字没改），
但它**改变会发生什么**——深到老友，就有一场只属于这两个人的戏。这也回答了"关系值攒出来干嘛"。

**不抄**：恋爱／结婚线（方案第七节已排除）；也不做"多个心事件档位"（一期只做**老友**这一个门槛）。

## 二 · 设计

```js
const HEART={ at:35, dur:90 };
// decide() 里、平常闲聊之前：
{ const 心=heartMate(w, ag);            // 两边都 ≥35 ＋ 同屋 ＋ 对方空闲 ＋ 这一对还没交过心
  if(心){ const o=心.mate;
    心.r.heart=1; relRec(o, ag.id).heart=1;                       // 旗子两边一起记（借用既有条目）
    ag.activity={type:'chat',label:'和'+o.name+'聊了很久'};  ag.busyUntil=w.t+HEART.dur;
    o.activity={type:'chat',label:'和'+ag.name+'聊了很久'};   o.busyUntil=w.t+HEART.dur;
    logAct(w, ag, '交心：和'+o.name+'坐下来好好聊了一回', …);      // 两条日志，前缀都固定"交心："
    logAct(w, o,  '交心：和'+ag.name+'坐下来好好聊了一回', …);
    return; } }
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **门槛 35（老友）** | `HEART.at`，与第 88 单的档位表同一个数 | 不放新尺子；"老友"这个词本来就是这个意思 |
| **两边都过线** | `relGet(o, ag.id)>=HEART.at` 才算 | 关系是**半张表**（A 觉得熟、B 未必），可"交心"这场戏要**两个人都认** |
| **只占空闲** | 排在上班／吃饭／睡觉之后 | 与第 62／64／73／81 单同一条红线：正事一概不碰 |
| **不掷骰子** | 条件成立就发生 | 照第 64 单"他的日子，必买"：确定性才可复现、才能当证据 |
| **一对人只一回** | 布尔旗子挂进 `ag.rel[对方].heart` | **零新增世界状态**；旧档缺这个字段＝没交过心，照样跑 |
| **两条日志** | 前缀固定"交心：" | 归类表按前缀匹配（第 47／87／88 单那套）；两条都归类，摘原文可以引 |
| **上卡** | `heart` 甲级 **2.0** ＋ 摘原文引那两句 | 一对人一辈子一场，够当天的卡 |

## 七 · 已知接受项

1. **一期只有"老友"这一个门槛**：星露谷有多个心事件档位，本作先做一个（家人一样那档留着，要做再说）。
2. **"聊了很久"没有专属画面**：与平常聊天共用 `chat` 活动（只是标签与时长不同），日志与剪辑卡才是它的现身处。
3. **一场 90 分钟**是拍的（`HEART.dur`）：够长到"这一天就这么过了"，又不至于把半天吃掉。
4. **只发生一次、不再重来**：关系后来掉了（冷线）也不会再触发——"交过心"是不可逆的。
5. **玩家不在关系网里**：你发的短信不会触发交心（照第 88 单那条口径）。
