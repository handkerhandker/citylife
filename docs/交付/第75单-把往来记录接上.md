# 第 75 单 · 把「往来记录」接上（它此前是个死面板）

> 一句话：短信页下半栏写着「**往来记录 · TA 的回音也在这里**」，可它是**死的**——
> `#ph-history` 只在建页面时塞过一句静态占位（"还没有往来。发一条试试——…"），
> **`renderPhone()` 从来没更新过它**：你发多少条短信，那栏永远写着"还没有往来"。
> 本单把它接上：按人分栏、时间倒序、带时间戳与回音，空态照实说。
> 指纹：**SIM 块 md5、世界指纹、门禁指纹三个全都不动**——这是纯 DOM 层的单（`43a742f3…`／`f23e62ed…`／`90242cc8…` 逐字节原样），
> 只有界面涨号 v72 → **v73**。

## 一 · 缘由（同一族病的 UI 版）

第 70 单刚治过"**地图上画着、却没人去过**"（夜谈角），第 17 单立过"**界面文案提到的操作必须实测可点**"。
本单是同族病的第三个现场，只不过这次是"**界面上写着会显示，可它从不显示**"：

```
$('#ph-history').innerHTML='<li class="faint ph-empty">还没有往来。发一条试试——…</li>';   // 只在 buildPhone() 里
// renderPhone() 里一行都没有 ⇒ 永远停在空态
```

一栏明写着"TA 的回音也在这里"，玩家却一次都没见过回音。**面板许了愿，代码没兑现**。

## 二 · 设计（纯 DOM 层；取词一处定义）

```js
function phoneHistory(w, id, 上限){        // 按人分栏、时间倒序、有上限
  for(let i=w.log.length-1;i>=0 && 条.length<n;i--){
    const e=w.log[i];
    if(e && e.type==='player' && e.agent===id) 条.push(e);
  }
}
function phoneHistoryHTML(w, id){ … 空态照实说 / 每条带时间戳与回音 … }
// buildPhone() 与 renderPhone() **两处**都调它（后者每帧刷新 ⇒ 切人、收信都会跟着变）
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 数据源 | 既有的 `w.log` 里 `type==='player'` 的条目（"读到了你的短信「X」"＋TA 的反应） | 玩家看到的回音本来就在日志里，不新造一份账 |
| 分栏 | 按 `e.agent===当前选中的人` 过滤 | 选谁看谁，切人即换 |
| 顺序与上限 | **时间倒序**、默认取最近 **8** 条 | 面板高度有限，先看新消息 |
| 空态 | 照实说"还没有往来。发一条试试——…" | 与"还没跟谁聊过"同款口径 |
