# 第 62 单 · 江灯节（第一个"年"尺度的公共活动）

> 一句话：本作原来只有"周"这一把日历尺（周日街市、周五夜市）。本单把它推到**年**——
> **每年第二个月 15 号晚上 19:00–23:00 江灯节**：提前一周预告、当天晨报再提一次、开灯、收灯报数，
> 四人里大半会去江边**放一盏灯**（−¥5）。一年一次，所以那一晚是特殊的。
> 指纹：**只有 SIM 块 md5 变**（`9756b790…`）——因为 30 天的指纹窗口根本走不到第 45 天；**它是不是真会发生，靠构造证**。

## 一 · 缘由（把"日子感"从周拉到年）

第 56–58 单把"公共活动"这一层立了起来（周五夜市、云港晨报），但那三样都长在**周**上。
同类作品里最能立住"日子感"的恰恰是**一年一次**的东西——星露谷的四季节日、动森的年度活动。
本单做第一个。

## 三 · 设计（零素材、零 AI、零新锚点）

```js
const FESTIVAL={ name:'江灯节', month:2, dayOfMonth:15, open:19*60, close:23*60, p:0.8, cost:5,
                 noticeMin:7*1440, yearDays:360 };
```

**"年"是怎么来的**：本作原本没有年，只有 `dayOf`（第几天）。但交租走的是 `day%30===2`——
**30 天一个月早就是既成事实**。本单顺着它定义 **12 个月 ＝ 360 天 ＝ 一年**，节日固定在年内第 45 天。

| 要件（照调研） | 落成 |
|---|---|
| 提前**一周**预告 | 「今年的江灯节在2月15日晚上 19:00，江边步道见。（D45 19:00）」——**哪天、几点、在哪** |
| 当天再提一次 | 08:10 的**晨报**加一句「今晚是江灯节，江边放灯。」（按**日号**判，不按时刻开窗） |
| 开灯／收灯 | 19:00「江灯节开灯了，江边一盏一盏亮起来。」／23:00「江灯节收灯了，今晚一共放了 N 盏灯。」 |
| 行为 | 时段内**空闲**的人按 `p=0.8` 去江边（既有的 `river_walk` 锚点）**放一盏灯 −¥5**；只占空闲那一档，上班／吃饭的钱／睡觉一概不碰 |
| 上卡 | 放灯那一刻把日志原文抄进 `ag.lastFest`（第 59 单"落笔抄录"口径），剪辑层出一张**甲级 2.6** 的卡项（每人每年至多一条） |

**与周五夜市撞车时**：节日优先（一年一次 vs 每周一次）——源码里节日那一支排在夜市之前，注释写明。

## 五 · 主判据（**构造**，因为 56 天的常规样本走不到第 45 天）

构造方式：把世界直接推到**节日前一晚 06:00**（只改 `w.t`，其余状态照旧——本段量的是"到点会不会说、会不会有人去"），
然后连跑 3 天：

| 读数 | 实测 | 判据 |
|---|---|---|
| 江灯节日期 | **D45 19:00**（年内第 45 天） | 与 `(月-1)×30＋日-1` 一致 |
| 三条播报 | 预告 **1**／开灯 **1**／收灯 **1** | 各恰一条 |
| 当天晨报 | 3 条晨报里 **1 条**含"江灯节"（就是节日当天那条） | 恰一条，且不是别的日子 |
| 当晚放灯 | **12 盏**（四人里有重复去的） | ≥2 盏 |
| 经济后果 | **¥60 ＝ 12 × 5** | 每盏 −¥5，逐笔对得上 |
| **一年只此一次** | 节后再跑 **30 天**：三条播报**一条都没再出现** | 0 条 |
| `festAt` | 指向明年（距当时的 `w.t` **471660 分钟**≈328 天） | >29 天 |

## 六 · 三个指纹：**只有 SIM 块 md5 变**

| 指纹 | 改前（v61） | 改后（v62） |
|---|---|---|
| **世界指纹** | `2475bfdb2434ff43d2183e1c2775fecf` | **不变**（同值） |
| **门禁指纹** | `0d8717f0589cda5170340595c8ee4c16` | **不变**（同值） |
| **SIM 块 md5** | `77c8fe6433e107c45e1d0fc0b9678ee6` | **`9756b7901489f24c78559c3f61292768`** |

**为什么前两个原样**：世界指纹与门禁指纹都只看**头 30 天**，而江灯节在第 45 天——**窗口根本走不到**。
这不是"没生效"，是"这一单的东西在窗口之外"；它到底会不会发生，由第五节那套构造证明 ✓。
（这也是本单登记的一条口径：**一年尺度的改动，三个指纹都看不见**，必须另附构造证据。）

## 八 · 已知接受项与盲区（照实登记，不粉饰）

1. **"年"是新定义的**：12 个月 × 30 天 ＝ 360 天，顺着交租的 `day%30` 推出来的；
   如果以后要真季节，得先把这套日历改成正本（本单只在注释与交付件里写清）。
2. **一年一次 ⇒ 常规样本看不到**：门禁靠构造验；**三个指纹看不见它**（见第六节）。
   玩家要看到，得真的玩到第 45 天（或开高倍速跑）。
3. **节日只有一天、没有连着的气氛**（比如前后几天街边挂灯）；也没有"节日专属目标"——
   目标池里目前没有"去看灯"这一条（要加就是第 60 单那套池子的活）。
4. **放灯会重复去**（12 盏来自 4 个人）——一晚反复去放，读起来略绕；要不要"每人每晚只放一盏"，
   属另一单（改法是给 `decide` 那一支加一个当晚标记）。
5. 第 39 单那笔**冷读测试欠账仍未补**。
