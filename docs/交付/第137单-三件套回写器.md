# 第 137 单 · 三件套回写器（`tools/closeout/writeback.cjs`）——**工作流工具、产品零改动 ⇒ 不涨号**（仍 v116）

> 一句话：每单收工都要手写一份 `updateN.cjs` 回写"交接说明／待办"——132／133 两单在**同一处**笔误上连发
> （行尾多一个「）」，第 134 单已补门禁）。本单把回写收成注册工具：**不再手抄「已知结尾」**、四道硬拒、
> 正式写完后自动跑 linegate；本单的三件套就是由它写的（狗粮）。

## 一 · 它治的是什么（都来自真实现场）

| # | 现场 | 根因 |
|---|---|---|
| 1 | 132／133 两单行尾连发 `。））` | `updateN.cjs` 里 `新尾` 自带一个「）」，末尾又加一个——**照抄上一单的模板**把笔误也抄了过去 |
| 2 | 手抄「已知结尾」再拿它定位 | 旧条目的收尾字符串是**手抄**进脚本的；抄错一个字就"找不到/找错位置"（引擎是字符串匹配，不报错就写歪） |
| 3 | 提交消息的引号被 Shell 拆包（本单开工前刚撞过一次） | 同类"手工步骤"风险的另一例——**不在本工具射程**（登记见第五节） |

## 二 · 工具做什么（`node tools/closeout/writeback.cjs …`）

| 件 | 做法 |
|---|---|
| ① 基线行追加 | 在 `交接说明.md`／`待办.md` 的**第 2 行末尾**追加单条——不抄"已知结尾"，改完可**直接重跑定位** |
| ② 块插入 | 「交接块」插到 `第 78 单·三项自测全套复跑` 锚点前；「待办块」插到 `## 下一单候选（按优先级）` 锚点前 |
| ③ 版本行 | 可选 `--旧版=v116 --新版=v117`（成对给；恰好一处，找不到即拒） |
| ④ 四道硬拒 | 单条以单「。）」收尾（`。））` 坏形态零命中）／**疑似已回写过**（该单尾巴已在⇒拒）／锚点找不到或不唯一⇒拒／单条多行⇒拒 |
| ⑤ 收尾 | 全量校验 → 落盘 → 读回终验 → **自动跑 `node linegate.js`**（红则退出码红） |
| 用法 | 正式：`--单=137 --单条=<文件> --交接块=<文件> --待办块=<文件>`；预演加 `--试运行`；自测：`--自测` |
