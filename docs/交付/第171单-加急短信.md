# 第 171 单 · 加急短信（"它会放下能停的事，优先回你"）——v138 → **v139**

> 一句话：《无心云志》公告卡 03 的候选落地——手机页多一个「**加急**」勾选框；加急的信到了，
> **能停的活动**（work／sleep／nap 之外）下一拍就把忙点拉回来，让 TA 先读到；
> **停不住的**照旧等忙完，回话里明说。发送与读取**零 rng**；不勾加急一切照旧。

## 一 · 出处（用户提供，登记在 `docs/规划/借鉴调研-2026-10-04.md` §五）

《无心云志》公告卡 03：「有急事可以发**紧急短信**，它会**放下能停的事，优先回你**；
忙着**无法中断**的事时，暂时打不通。」

**抄哪一条**：加急＝"能停的先停、停不住的说明"这层语义。
**哪一条不抄**：电话那套"打不通"不做（本单只做短信；电话是另一档，见调研文档候选 A）。

## 二 · 实现

| 件 | 做法 |
|---|---|
| 入口 | 手机页输入框旁一个「加急」勾选框（`#ph-urgent`；额度为 0 时同门禁用；发完自动取消勾选） |
| SIM·信 | `sendCustomMessage(w,id,text,urgent)` 第 4 位；`inbox` 里带 `urgent:true`；发出的日志写"发了**一条加急短信**" |
| SIM·让路 | `advance10` 里、逐人决策**之前**：收件箱头是加急且当前活动**不是** work／sleep／nap ⇒ 忙点拉到下一拍 ⇒ 下一拍 `decide()` 先读到 |
| SIM·回话 | 读到时的回话分两种口吻：能停 ⇒「你说急，手里的事先撂下了。」；停不住 ⇒「"急"字看到了，手头这摊停不住，一松手就回你。」 |
| 红线 | 发送/读取**零 rng**、不加钱不扣钱、不新增存档字段（`urgent` 只是信里的一个布尔） |
