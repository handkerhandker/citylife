# 第 72 单 · 题面带着台词走（夜谈时聊的就是那件事）

> 一句话：上一单给夜谈定了"今晚聊什么"，可那句题面**只是贴在日志上的一行字**——
> 四个人坐下后说的话仍是平常那套随机台词。本单把它接上：**在夜谈角、两人都坐着的时候**，
> 开口那一句从"话题池"里取（模板带 `{题}` 占位符，用当场题面填），接话走新开的 `talk` 组。
> 实测：24 个周日夜里，**夜谈角上的 8 场对话场场带当天题面**，别处 48 场**一场都不带**。
> 指纹：**只有 SIM 块 md5 变**（`e6ddaa57…` → **`de5324c5…`**），世界与门禁指纹**逐字节原样**
> （抽签次数没变，变的只是"从哪张池里抽"）。版本：v69 → **v70**。

## 一 · 缘由

第 71 单交付时登记的第一条欠账就是它："**话题只是'题面'，不会带着台词走**"。
那句话点破了当时的尴尬：题面写在日志里，可四个人嘴里说的还是"楼下那家便利店"之外的事——
**题面与台词是两张皮**。

## 二 · 设计（零素材、零 AI；只加台词与一条取值分支）

```js
const TALK_OPEN={ work:['{题}。这事你们怎么看？','说说{题}吧，我先听。'], … };   // 四类各 2 条，条条带占位符
function talkOpenLine(workKind,i,题面){ … s.replace('{题}',题面) … }              // 替字**只有这一处**
CHAT_FB_REPLY[k].talk = [ … 四类各 3 条，刻意接得住任何题面 … ]                   // 第八类接话组
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| 什么时候走话题 | **两人都坐在夜谈角**（`ag.anchor==='plaza_talk' && mate.anchor==='plaza_talk'`）且正在夜谈窗口 | 题面只在那一场里成立 |
| 优先级 | **生日问候 > 夜谈话题 > 平常那套** | 人对人的事优先于对话题的事（照第 65／72 单一条线） |
| 替字口径 | `talkOpenLine(workKind,i,题面)` 一处替换 | 全站 `.replace('{题}'` 恰 1 处（门禁咬住） |
| 题面怎么复算 | `talkTopicOnDay(day)`（第 71 单那个取题函数的**日号入口**） | 门禁普查要按**日志条目自己的日子**复算题面，而不是拿"现在"的题面硬套 |
| 接话 | 新开 `talk` 组（`CHAT_KINDS` 第八类） | 第 48 单那套"按开口类别取组"原样管用 |
| 抽签次数 | 仍是**一次开口 ＋ 一次接话** | 改的只是"从哪张池里抽" |

## 七 · 已知接受项与盲区（照实登记，不粉饰）

1. **题面进台词，但"聊得像不像"仍由模板决定**：开口 2 条／人、接话 3 条／人，一轮下来会重复
   （同人同日同组去重只在**池尽**时重置）。要更耐读就扩池（`TALK_OPEN`／`talk` 两处）。
2. **AI 增强那条路没接**：既有 `enhanceChat` 拿到的仍是「开口」「接话」两句与话题类别，
   题面**没有**单独喂给它——本作本地没有中转线路，这一层今天测不到（照实登记）。
3. **只在夜谈角发生**：站在广场别处（不在 `plaza_talk` 锚点上）聊天仍走平常那套。
4. **雨天话题依旧没做**（第 71 单登记的欠账，原样挂着）。
