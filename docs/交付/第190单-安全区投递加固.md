# 第 190 单 · 安全区投递加固（页面主动问壳 ＋ 屏/壳读数进浮层）——v154 → **v155**

> 一句话：真机反馈"装了 v153 啥变化都没有"。先拆包**排除了打包问题**（v153 包里页面就是 v153、
> 壳的安全区代码也在）；剩下两种可能——① 手机上跑的**还是旧页面**；② 安全区**没被送进页面**。
> 本单把投递补成"两条腿"（壳推 ＋ 页面主动问壳）、壳在系统不报数时用系统声明的状态栏高度兜底，
> 并把**屏幕尺寸**与**壳测安全区**打进浮层——装上后一眼能看出卡在哪一环。

## 二 · 改了什么

### ① 壳（`apk/android/app/src/main/java/com/yungang/citylife/MainActivity.java`）

- 新增 JS 接口 **`getInsets()`**：页面可随时问壳要"上,下,左,右"（CSS px，已除 density；
  第 5 位是"上值是否来自兜底"的标记）。主线程调用时顺手现量一次，桥线程调用返回最近一次量的缓存。
- 补推扩档：开机补拍 4 拍 → **6 拍（到 8 秒）**；并新增 **`onWindowFocusChanged` 时再推一次**
  （首次显示/回到前台，往往正是页面刚加载完的那一刻）。
- **兜底**：竖屏时若宿主压根不报上值（`上 <= 0`），用系统声明的 **`status_bar_height`** 顶上
  （返回值标 `(备)`）。横屏不兜（横屏上面本就强制 0）。

### ② 页面（`city-life-framework.html`）

- 新增 **`拉壳安全区()`**：启动后 80/500/1500/3500/7000 ms 各问一次壳，`resize`／`orientationchange` 再问；
  仍然**只补"平台没给值"的轴**（口径同第 186 单，不跟平台抢）。
- 浮层加两段读数：**`· 屏 W×H`**（物理屏 CSS 尺寸，用来判"WebView 有没有铺满屏幕"）与
  **`· 壳 t… b… l… r…`**（壳最近一次量到的值，带 `(备)`）。设置页说明文字同步。

### ③ 判据与登记

- `harness.js` 第 190 单 **4 条结构判据**（页面拉取／补拍时机／浮层两段读数／壳源码 `getInsets`＋兜底）
  ＋ 反向自查；反向自查登记表同步（**106 组**对齐）；
- `tools/diag-overlay/probe.mjs` 新增第 **⑥** 用例："注入假壳接口 ⇒ 页面拉到值（`--sa-t=17px`）、
  浮层显示壳值"；顺带把 189 那条被新代码"咬版式"的尾引号判据改成结构锚、把样张截断 200 → 400 字；
- `tools/smoke/registry.cjs` 备注同步。
