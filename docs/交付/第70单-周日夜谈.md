# 第 70 单 · 周日夜谈（把地图上那个「夜谈角」变成真会发生的事）

> 一句话：广场东北角那块地从第 12 单起就画着、还标着「夜谈角」，注释里写着"周日夜谈聚集点"——
> **可从来没有一个函数让任何人去过那儿**。本单把它兑现：**周日 20:00–22:00**，空闲的人过去坐下
> （**不花钱**，与周五夜市"买小吃"刻意分工），**22:00 一条散场播报**报出今晚坐了几个人。
> 指纹：三个数**全变**（世界 `98b76d2e…` → **`f23e62ed…`**、门禁 `ac39e5e9…` → **`90242cc8…`**、
> SIM 块 md5 `d207e5ca…` → **`7ea77b99…`**）——新锚点 ＋ 新行为，都在 30 天窗口里，属预期。
> 版本：v67 → **v68**。

## 一 · 缘由：地图替我们许了一个愿，代码没兑现

第 12 单放样广场时画了「夜谈角」（列 24–26 × 行 15–17），注释白纸黑字："周日夜谈聚集点"。
可全仓搜 `plaza_talk` 零结果——**没有锚点、没有一个分支去过那儿**。玩家看得见那块地、
看得见那行地名，却永远等不到有人去坐着聊天。

这与第 17 单立的那条教训同型（"任何界面文案提到别处能做的操作，交付前必须实测可点"）——
本单是它的地图形版本：**地图上画着的地方，交付前必须真有人去。**

## 三 · 设计（零素材、零 AI）

```js
const TALK={ day:6, open:20*60, close:22*60, p:0.5 };   // 周日 20:00–22:00，空闲者半数过去
const ANCHORS.plaza_talk={room:'street',x:25,y:16,label:'广场·夜谈角', s:'广场'};
```

| 要件 | 落成 |
|---|---|
| 一周一次的固定场 | `nightTalkStartAt`／`inTalk`／`thisWeekTalkAt` ：照第 56／57 单夜市那一套（**含那条教训**：散场播报要用"本周"而不是"下一个"） |
| 去处 | 新锚点 `plaza_talk`（房间 'street'），四个站位 `[[-0.5,-0.5],[1,-0.5],[-0.5,1],[1,1]]` 全落在夜谈角矩形里 |
| 人数 | 数**人头**不是人次：他坐一会儿、起身、又回来，播报里还算一个人（江灯节数"几盏灯"是人次，两处口径不同是有意的） |
| 散场 | 22:00 一条世界级播报：「夜谈散了，今晚在夜谈角坐了 N 个人。」（`BACK_SUM` 补一桶 `talkDone`） |
| 与夜市的分工 | 夜市＝周五 19:00–23:00、花 ¥8 买小吃；夜谈＝周日、**不花钱**、纯坐下说话 |

## 六 · 顺手修的一处"靠运气"的反向自查（第 48 单那条）

第 48 单的"同日零重复"有条反向自查：**只把「说自己」那一组砍到 1 条**，指望陆知秋那天两次抽到
「说自己」⇒ 冒重复。本单的世界位移（多了周日晚上这一场）之后再没撞上，读数 0 ⇒ **假红**。
它本来就是运气型自查（那一类"说自己"的对话不热）。

改法照第 63／66 单的口径：**把病态写足**——一刀把陆知秋**每一组**接话都砍到 1 条，
他那天只要接两次话就必然重复（实测 **8 次**）。**判据一字没松，松的只是"病态够不够病"。**

## 九 · 已知接受项与盲区（照实登记，不粉饰）

1. **只是"坐着说话"，没有新台词**：夜谈本身只落了"坐下"这条日志；说什么仍走既有闲聊那套
   （同屋随机开口／接话）。要"夜谈有话题"（比如聊这一周的记忆）属另一单。
2. **人数看运气**：`p=0.5` 且要"那一刻空闲"——实测 4 个人头，也可能只到 1–2 个（没人也照报 0 个）。
   要更热闹就调 `p` 或改触发条件（属体感题，等你一句话）。
3. **雨天照去**：没做"下雨不去夜谈"——本作的雨只刮到"出去玩"那三支（第 49 单口径），本单沿用；
   要做就在 `TALK` 里加一条雨档（与 `RAIN_RULES` 同型）。
4. **`p=0.5` 是我拍的**，没有像第 52 单那样做 A/B 定标（这一支没有"目标持有者"可对照）。
