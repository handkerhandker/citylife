## 一 · 缘由

视觉层二期剩下的那一档就是「**铺满空房间**」。现状：

| 房间 | 谁在画 |
|---|---|
| 公寓三间（客厅／厨房／卧室） | `apartment.png` 整体接管（第 16 单起） |
| 便利店（12×10）／公司（10×9） | **一块纯色矩形** |
| 滨江公园／江边步道 | 室外，纯色（本单不碰） |

第 35 单给这两间点上灯之后，**两块空地反而更显空**——占地最大、零细节，是画面上最扎眼的两处。
故本单做「零素材」那一档：只用画布原语把它们从「空地」变成「铺了地砖的屋」。

**为什么先做这一档、而不是直接上素材流水线**：流水线要的是 LimeZu 原包，而**原包不在这台机器上**
（第 36 单开工实测：`CITYLIFE_MI_DIR`／`CITYLIFE_MI_ZIP` 均未设，全盘限深搜索无命中；它只在私有
仓库里以 Release 附件形式存放）。零素材这档**不浪费**——日后流水线那版接管的方式与公寓三间
**完全相同**：把那两间加进 `PIX_ROOMS` 即可，本段会自动跳过（交集由门禁看着，必须是空的）。

## 二 · 做法

新段 `/*ROOMTILE-START*/…/*ROOMTILE-END*/`：

| 常量／函数 | 内容 |
|---|---|
| `TILE_ROOMS` | `['store','office']`——还没被拼合图接管的两间 |
| `TILE_LINE`／`TILE_MAJOR` | 地砖细缝 `rgba(255,255,255,.055)`／每两格一道粗缝 `.10` |
| `TILE_WALL=0.18` | 后墙带：把**房间自己的边色**压到 18% 铺满顶上一格（不引入新色） |
| `TILE_SKIRT` | 踢脚线 `rgba(0,0,0,.22)`，贴房间底边 3px |
| `roomTile(r)` | 上面四样一次性画完 |

**由构造保证：一笔都不出房间。** `roomTile` 头一件事是
`ctx.beginPath(); ctx.rect(房间矩形); ctx.clip();`——所有笔画被裁在房间矩形内。
门禁另有**逐笔核**：把 `fillRect` 与每一段线的两端逐个比对房间矩形，出界即判红
（实测两间共 4 个矩形 ＋ 35 段线，出界 0 笔）。

**射程：只画地面与墙，一件家具都不画。** 家具会占格，而本项目「逐帧脚底不得进实体格或家具占格」
是走位三铁律之二（第 20 单立的硬红线）——要加货架／工位，必须**同时**改 `PIX_SOLID` 与站位表并
重跑走位门禁，那是另一单。故本段**零 `PIX_SOLID` 引用、零 `ANCHORS`、零 `STAND_SPOTS`**（有断言）。

## 七 · 已知接受项与等决策

**接受项**
1. **房间里还是空的**——本单只铺地砖与墙，**没有货架、没有柜台、没有工位**。理由见第二章
   （家具会占格，触碰走位红线）。真正的「室内篇」要连家具一起做，那必须同时改 `PIX_SOLID`
   与站位表、并重跑走位门禁。
2. **不是真瓷砖**。零素材档用的是画布画的缝，观感比 `apartment.png` 那种手绘质地糙；
   那是素材流水线那版的活（原包不在这台机器上，见第一章）。
3. **公园与江边仍是纯色**（室外，本单不碰）。
4. **地砖缝在极小缩放下会糊成一片**（细缝只有 1px）。可接受：那一档本来就只看得见色块。

**等决策**
- 第 33 单那条仍挂着：**夜里够不够黑**（`SKY_MAX_ALPHA` 现 0.34；第 35 单点灯后建议
  「室外可以更暗」，两单一起拍）。
- 本单新提一条：**要不要上素材流水线把便利店／公司换成真瓷砖**？代价是要先从私有仓库取
  LimeZu 原包（几十 MB 级下载 + 改 `build_assets.py` 配方），收益是这两间从「画的地砖」
  变成与公寓同一质地的真室内。**要你点头才动**（属大改动）。
