## 一 · 定标复核（先量再改）

**方法**：同一批 12 颗种子，各跑到江灯节那一晚；A＝现行（`0.80+0.15=0.95`）、B＝把 `goalKnob('fest')`
那 **0.15 抹成 0**（在内存里改一份副本，不动仓库）；数"每人**第一次**放灯的钟点"。

| 组 | 到场 | 平均钟点 |
|---|---|---|
| A 带旋钮（0.95） | **3.42 人/场** | 19.41 点 |
| B 摘旋钮（0.80） | **3.17 人/场** | 19.45 点 |
| 差 | **0.25 人/场** | **2 分钟**（噪声级） |

**结论**：旋钮**小但非零**（不是"完全没用"，第 90 单那句"只影响谁去得早"只说对了一半：
它影响的是**到场人数**，不是时刻）；而"去得早"这件事**本来就由概率决定**——0.80 与 0.95 在 24 个拍里
前几拍就中了，**没有可提前的空间**。

## 二 · 重启：把效果换成"他真的是头一批到江边的"

```js
const 有灯=(typeof goalOf==='function'&&goalOf(ag)&&goalOf(ag).k==='lantern');
const 头一小时=有灯 && inFestival(w) && PURE.minuteOfDay(w.t)<FESTIVAL.open+60;   // 19:00–19:59
if(inFestival(w) && (ag.flags.wantFest || 头一小时 || w.rng()<Math.min(0.98,FESTIVAL.p+goalKnob(ag,'fest')))){
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **一小时内必去** | `头一小时` 排在 `w.rng()` **之前** | "拿了目标的人惦记这件事"——空着就出发，不等抽签 |
| **只给拿目标的人** | 判据读 `goalOf(ag).k==='lantern'` | 与 `fest` 旋钮**同一处定义**，不另立一套"谁会去"的判据 |
| **与"短信叫他去"同档** | 排在小括号里 `wantFest` 之后 | 玩家点名的优先级最高（第 57／63 单口径） |
| **概率那条路照旧** | `+goalKnob(...)` 一个字没动 | 一小时之后仍然是"掷骰子"，只是目标持有者多一份底 |

**实测（新增丙节，`tools/fest-audit/probe.cjs`）**：同一批 12 颗种子、三种版本各跑一遍那一晚——

```
 带旋钮：3.67 人/场，平均 19.45 点
 只摘概率：3.58 人/场（旋钮自身的边际效应 0.08 人/场）
 目标全停：3.17 人/场（**"去看灯"这条目标的总效果** 0.50 人/场、0.4 分钟）
```

——**目标的总效果 0.25 → 0.50 人/场（翻倍）**；而旋钮自己那 0.15 的边际效应降到 0.08
（因为"头一小时必去"已经把目标持有者覆盖住了，这正是重启的目的：**机制不重复、效果更实在**）。
