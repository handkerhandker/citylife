# 第 129 单 · 短信页「分人未读」（DOM 层；版本 v112 → **v113**）

> 一句话：第 80 单给了短信页签一个**总角标**，但分不清是**哪个人**来的（它登记的两条遗留：①只有总角标；
> ②水位是"最后一条"、不分人）。本单补上：每个人的按钮上挂一个自己的小角标（与总角标共用**同一处**
> "未读条数"口径，多一个可选 id），**点到谁＝这一路读过了**（分人水位随存档信封走）；
> 旧档没有分人水位 ⇒ 用全局水位兜底，**不会一开页就炸出一排红点**。
