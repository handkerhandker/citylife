> 一句话：第 91 单给了"交心"一场戏，但只挂在**老友**（35）那一档——顶格的「家人一样」（50）除了一个名字
> 什么也没有。本单照同一份出处（星露谷的 `heart events` 本来就不止一场）补上第二场：

> 旗子从"有没有交过心"变成**心级**（1＝老友那场／2＝家人那场），零新增世界状态。
> 版本：v88 → **v89**。指纹：世界 `b5935386…` 与门禁 `d759a1f6…` **原样**，SIM 块 md5 `9d6b7ab3…` → **`678478ea…`**。

## 一 · 缘由

第 91 单交付时登记的第一条接受项：

> ① **一期只有"老友"这一个门槛**（家人一样那档留着，要做再说）。

出处（沿用第 91 单那条，本单未另查新源）：星露谷 wiki·Friendship——
「As friendships deepen, … cut-scenes called **heart events** occur, …」——**关系每深一档，就该有一场自己的戏**。

## 二 · 设计

```js
const HEART={ at:35, dur:90, at2:50, dur2:150 };     // 老友档／家人档
function 心级(r, 对方值){                             // 两边都认的那一档（取两半的较小值）
  const v=Math.min(relV(r&&r.v), relV(对方值));
  if(v>=HEART.at2) return 2;
  if(v>=HEART.at)  return 1;
  return 0;
}
// heartMate() 现在返回 {mate, lv, 演过}：还有**没演过的那一档**才成立
// 那一支按 lv 分岔：
if(心.lv>=2){ 两人都去 river_walk、stroll 150 分钟、'交心：和X一起出门走了一趟' }
else        { 坐下聊 90 分钟、'交心：和X坐下来好好聊了一回' }             // 第 91 单那一场
function 记心级(ag,id,lv){ const r=relRec(ag,id); r.heart=Math.max(r.heart|0, lv|0); }   // 只升不降
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **两档两场** | `at`／`dur`（老友·坐着聊）＋ `at2`／`dur2`（家人·出门走走） | 照出处"每深一档一场戏" |
| **两边都认** | `心级()` 取两半关系的**较小值** | 关系是半张表（第 88 单口径），"两个人都认"才算数 |
| **心级只升不降** | `Math.max(旧, 新)` | 与第 91 单"交过心不可逆"一致 |
| **旧档兼容** | `heart:1` 照旧算"老友那场已发生" | 顶格之后会**补上**家人那场（不重复老友那场） |
| **零新增世界状态** | 还是写在 `ag.rel[对方].heart` 里 | 只是从布尔变成 1／2 |
| **不掷骰子** | 条件成立就发生 | 照第 64／91 单那条 |
