## 三 · 口径与自坑

- **两个调用点、两种层序**：草必须在**家具之前**（否则草叶会画到长椅/树上）；石子必须在**路面之后**
  （否则被路的底色盖掉）。闸三把这两条层序都钉住 ✓。
- **哈希要"整数且稳定"**：`格哈希` 用 `Math.imul` 组合两轴（照第 263 单店猫哈希同族手法）——同一格
  每一帧都落在同一处，探针的"重复稳定"才成立（实测三块盒两次读数**逐字相同**）。
- ★自坑照实登记：公园"草色"判据第一版照惯例定 ≥200 ——**旧版也有 810 像素落进 (66,86,64)±2**
  （灌木边／树影那族的绿），阈值不抬就新旧不分。修法＝把阈值定在 1000（新版 1285，两次读数完全一致），
  并把这条缘由写进探针注释；米色花是全新色（旧版 0）故 ≥40 即可。
- ★★**冒烟里的第二处工具链余量问题**：首跑 `save-fuzz/dom-probe.mjs` 判红（`throw er; // Unhandled
  'error' event`）——单跑**通过**（0/7 例不过），实测**约 4 分钟**；注册表给它的超时是 **300 s**，
  本机稍有并发就被 timeout 杀掉（症状长得像端口冲突，实为掐表）。修法＝超时 **300 → 600 s**
  （并写明缘由）；复跑 **85/85 全通**。
