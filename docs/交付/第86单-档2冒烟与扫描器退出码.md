## 三 · 结果（20 支：19 绿 / 1 红）

| 支 | 结果 |
|---|---|
| 档 1 七支（chat-pair／goal-audit／world-audit／fallback-pool×2／offline-catchup×2） | **全绿** |
| 档 2 十三支（live-walkgate／nameplate／night／fresh／**page-sweep**／soak／act-icon／night-lamp／room-tile／sky-tint／street-glow／catchup-shots／catchup-pop） | **12 绿 ＋ page-sweep 红** |

**那支红的不是产品，是工具自己**：`sweep.mjs` 的退出码写的是
`process.exit(读数.报错.length ? 1 : 0)` —— 而它页面里天然会有
**首屏 `ERR_ABORTED`、`favicon.ico`、本地没起的 `/relay` 404**（历次交付件都写着"与历次同源"）。
于是它**每次都是 exit 1**：读数里明明分了"真 JS 异常 0／网络类 21"，退出码却把它们混在一起。

**治法**（口径与它自己的读数对齐）：把"真异常"（`pageerror`／TypeError／ReferenceError／SyntaxError）
单独筛出来，**退出码只看真异常 ＋ 按钮失败**；网络类照旧进读数、只印不算。复跑：

```
按钮清单 23 条；点击 97 次；网络类报错 21 条（只印不算）；真 JS 异常 0 条；按钮失败 0 处
完成： …（退出码 0）
```
