## 一 · 缘由

第 99 单交付时登记的仍挂着第 ① 条：

> ① **只在角色详情里看**：现场页的气泡仍只显示活动名（第 51 单口径）。把独白也给气泡属"气泡二期"，另立单。

现场页是本作被看得最久的一页；气泡是它上面**唯一一块能读字的地方**（第 51 单定义：短文本 ＋ 指向角色的尾巴，
只给选中的人画）。独白不进日志墙（第 99 单口径），所以气泡是它最自然的第二个读者。

## 二 · 设计

```js
const BUBBLE={ …, thinkChars:20, lineGap:2, ink2:'rgba(236,229,208,.72)' };   // 第 100 单加的三个
function bubbleLines(ag){                    // 纯函数（照 bubbleText 先例）
  const 主=bubbleText(ag); if(!主) return [];
  const 想=(ag&&ag.activity&&typeof ag.activity.think==='string')?ag.activity.think.trim():'';
  if(!想 || 想===主) return [主];             // ← 没有独白（或与活动名相同）就一行
  return [主, 想.length>BUBBLE.thinkChars ? 想.slice(0,BUBBLE.thinkChars)+'…' : 想];
}
// sayBubble：宽取两行里较宽的那行，高＝行数×字号＋行距＋内边距；第一行主墨、第二行暗墨
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **两行** | 第一行活动名、第二行独白 | 一行说"在做什么"，一行说"在想什么" |
| **各压自己的上限** | 活动名 12 字（一期原样）／独白 20 字 | 独白本来就更长；上限各管各的，不动一期口径 |
| **没有就一行** | `!想 \|\| 想===主` 直接返回一行 | 不做样子（睡觉／走路这些没有独白） |
| **盒高随行数长** | `h=行数*size+(行数-1)*lineGap+padY*2` | 尾巴仍落在盒底中点；遮挡盒跟着变高（第 42 单让位表照旧吃得到） |
| **纯渲染** | 零 rng、零 SIM 写入、零新增字段 | 三个指纹原样作证 |
