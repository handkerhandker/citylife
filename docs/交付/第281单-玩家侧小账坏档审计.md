## 一 · 五例与判据（真页面、真点击）

把畸形小账塞进隔离上下文的 `localStorage` → 开页 → 点角色页（手账）／剪辑页（切"看收藏"）→ 读真 DOM 与 `state`：

| 例 | 喂进去什么 | 判据（收工态实测） |
|---|---|---|
| 小账·miles 全畸形 | `{sms:'x', replies:-5, notes:null, bdays:{}, calls:[], delivers:'9', picks:12345, bottle:2, countedLid:-1}` | 八个计数**全是非负整数**（口径见下）、`bottle===0`、`countedLid===world.lidSeq`、手账 **21 条**、计数形如 `N/21` ✓ |
| 小账·keeps 混合垃圾 | `[null,42,'x',[],{d:'x'},{d:9,name:7,items:[null,3,{id:{}}],q:['x',{text:'嗯'}],sc:'x'}]` | 只留 **1 条**（d=9）、收藏视图画出 **1 张卡**、零 pageerror ✓ |
| 小账·keeps 100 条超上限 | 100 条合法卡 | 载入后 **60 条**（KEEP_MAX）、首条 d=1 ✓ |
| 小账·ai 畸形 | `{day:'x', used:-3}` | **载入即读**＝`{day:-1, used:0}` ✓ |
| 小账·phSeenBy 畸形 | `{a1:'x',a2:-1,a3:'5'}` ＋ `phSeen=7` | `{a1:7,a2:7,a3:5,a4:7}`（坏值回退全局水位）✓ |

> **口径校准（审计顺手记下的一条）**：计数类八项的归一**本来就是"非负整数"**——`isFinite('9')` 为真 ⇒
> 数串 `'9'` 认成 `9` 是**设计**（`bootMiles` 注释原话"归一为非负有限数"），**不是漏网**；
> **严格布尔只对 `bottle`**（`true/1` 才算）。第一版判据按"一律归 0"写，当场假红——照实登记。
> 另：`ai` 那一例必须**载入即读**（游戏一跑起来成本闸就照常记当天用量——那是对的，读晚了会假红）。
