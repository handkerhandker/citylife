# 第 97 单 · 雨天的独白（在外的人会聊天气）

> 一句话：出处是我们自己那张调研表里新查的一条——动森 Nookipedia·Weather：
> 「**Villagers who are outside when rain is falling carry umbrellas and might also comment on the weather.**」
> 在同类作品里，**天气是被居民"说出来"的**；本作此前雨天只有"少出门"（第 49 单）和一条屋内标签，人嘴上不认这场雨。
> 本单让下雨时**散步那一类独白**改从"雨池"里抽（在外的人聊雨），**在家待着**那句也换一版（窗内看雨）。
> ⚠ 关键性质：`pickV` 无论池多大都**恰好消耗 1 次 rng** ⇒ 换池**不改 rng 流、不改世界指纹**——实测两枚指纹原样。
> 版本：v89 → **v90**。指纹：世界 `b5935386…` 与门禁 `d759a1f6…` **原样**，SIM 块 md5 `678478ea…` → **`3294f472…`**。

|---|---|---|

## 二 · 设计

```js
const RAIN_STROLL_THOUGHTS=[ '没带伞，索性慢慢走——反正都湿了。', …, '江面被雨点打出一层麻子。' ];   // 8 条
const RAIN_IDLE_THOUGHTS  =[ '雨敲在窗上，一下一下，很匀。', …, '翻了翻天气预报，明天还是雨。' ];   // 8 条
function 天气词(w, 晴池, 雨池, ag, 键){                       // 一处定义
  const 雨=!!(w.weather&&w.weather.rain);
  return pickV(w, 雨?雨池:晴池, ag, 雨?(键+'r'):键);           // ← 键也跟着换
}
// 6 处调用全改走它：周末出门逛逛／放灯／买蛋糕／散步（lo×4）／夜谈（lq）／在家待着（li）
```

| 要件 | 落成 | 为什么 |
|---|---|---|
| **换池不换抽签** | `pickV` 无论池多大都恰好消耗 1 次 rng | 只改"抽中的是哪一句"，不动事件流；两枚指纹据此**原样** |
| **键跟着换** | 雨天用 `lo`→`lor`、`lq`→`lqr`、`li`→`lir` | `pickV` 的看家去重按**键**存下标，**不同数组共键会串账**（既有注释点名的坑） |
| **雨池 8 条** | 单日雨池抽取峰值实测 **3 条** ⇒ 池意余量 ≥2 倍 | 照第 13 单那条"上墙池容量 ≥ 全城单日抽取峰值" |
| **窗内也有话** | "在家待着"那句一并换 | 出处说的是"在外的人会聊天气"；在屋里听雨同样成立，且那句本来就有雨天标签（第 49 单） |
