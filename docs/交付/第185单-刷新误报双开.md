# 第 185 单 · "刷新误报双开"（页标识按标签页存）——v150 → **v151**

> 一句话：**每次刷新页面都会弹一次冤枉提示**「另一个标签页也开着这个游戏…」（约 6 秒后自己收起）。
> 根因＝页标识每次加载都新生成，刷新后上一拍那条心跳（还在 10 秒保鲜期内、id 又对不上）
> 被当成"另一个标签页"；连旧页刷新收尾那笔存档也会撞上"存档键那条提示"。
> 治法：标识改存 **sessionStorage**（同标签页刷新不变、新标签页各起一个）＋ 心跳判据只认
> **不同的页标识** ＋ 存档键那条只认"**本页开钟之后**"的笔。

## 一 · 怎么发现的

拍诊断浮层样张时，截图里出现那条"另一个标签页也开着这个游戏"的提示——而当时只开着一个页。
写了个小脚本量了一把（`diag-tabwarning.mjs`，临时件）：

```
首次加载： 无提示
刷新一次： 有提示 ✗（只有一页）
再刷新一次：有提示 ✗
```

**门禁为什么没拦住**：第 135 单那支 multitab 探针只跑了"单开 12 秒不误报／双开要报／关掉自收"
三种情形，**"刷新"这一种根本不在场**——最坏样本没进门禁，就等于没有这道闸（第 15 条根因口径）。

## 二 · 改了什么

1. `本页id` 改存 **sessionStorage**（`citylife-tab-id`）：同一标签页刷新后仍是同一个"人"，
   新标签页各起一个；
2. 判据拆成两层：`心跳算别页(o)`（只判"不同的页标识"＋新鲜度）／`多开别页活着()`（取键）；
   **同 id 一律不算**——刷新时旧页收尾那两拍会带同一个 id 落盘，按"比我新"去判就会冤枉刷新；
   复制标签页（sessionStorage 被抄走、同 id）那种漏网之鱼由**存档键**那条兜底；
3. 存档键那条只认"**本页开钟之后**"写下的笔（撇掉刷新时旧页的收尾存档）。

## 四 · 双审计

**正向**：① 病是**拍样张时撞见**的，不是猜的；② 先量后改（修前/修后同一把临时量尺各跑一遍）✓；

漏网之鱼没有放过——用既有的存档键那条兜底并补测 ✓。
