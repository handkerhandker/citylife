# 第 181 单 · 真全屏铺满（地图铺满整屏 ＋ 系统那条白蒙层 ＋ 全屏方式开关）——v146 → **v147**

> 一句话：决策者在真机（鸿蒙＋卓易通）上指出两处——① 底部渐隐层糊住了页签栏／提示条；
> ② 横屏左侧与上侧只是"涂了相近的颜色"，地图并没有铺满。本单把两处都改掉：
> **撤掉底部渐隐**；**画布改成铺满整个窗口**（含系统栏与挖孔那一条），UI 才按安全区内缩；
> 顺带把系统那层**约 59% 白蒙层**的根因（浅色主题）换成深色主题，并加一个「全屏方式」开关供真机 A/B。

## 一 · 三处改动

### 1）撤掉底部渐隐层（壳）
上一版按交接文档画的"底部渐隐"是给**浅色** App 用的；本作深色底，它只会把页签栏／提示条糊白。
→ 直接删掉这一层；顶部渐隐也收窄到**只盖状态栏那一条**（不再下探 12dp 到 UI 上）。

### 2）地图真铺满（游戏）
`#cv` 从"内容格里的一张画布"改成 **`position:fixed; inset:0`（铺满整个窗口）**，
尺寸改按 `innerWidth/innerHeight` 算；`#content` 与 `.screen` 的层级/背景相应调整
（非现场页仍不透明，现场页透明露出地图），并整条链 `pointer-events:none` + 画布/浮层 `auto`
——**触摸一点没丢**（触屏探针 8/8 照过）。
效果：横屏时地图一直铺到挖孔边、竖屏时铺到系统栏下面；UI（顶栏／页签栏／场名／日志卡）浮在上面。

### 3）系统那条白蒙层 ＋ 全屏方式开关（壳）
- **根因**：系统栏的"对比蒙层"颜色跟着**主题亮暗**走。父主题是 `DayNight`（白天=浅色）⇒ 手势区盖 ~59% 白。
  → 父主题换成**深色** `Theme.AppCompat.NoActionBar`；两栏仍透明、图标仍浅色。
- 新增「**全屏方式**」设置（铺满＝默认／沉浸＝藏系统栏）：页面记在 localStorage 并调壳里的
  `SZGOShell.setImmersive(0/1)`；壳启动时读回同样一个键。**藏系统栏在卓易通上可能被宿主填黑杠**
  （交接文档实测），所以默认铺满、沉浸只作真机 A/B 用。
