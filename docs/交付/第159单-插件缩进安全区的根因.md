# 第 159 单 · "三边黑带／顶栏被遮"的根因：**插件在替我们把 WebView 缩进安全区** —— v158 → **v159**

> 一句话：真机截图 ＋ **装在本机包里的 `SystemBars.java` 源码**一起坐实——**WebView < 140 时，
> `insetsHandling="css"` 会让插件把整个 WebView 塞进安全区**（`decor.setPadding(left, top, right, bottom)`），
> 并把 `--safe-area-inset-*` 注入成 **0**。页面再按壳量到的值内缩一次 ⇒ **双重内缩**：
> 外面那圈"没画布的黑带"就是这么来的。三处改动：插件改 `disable`（安全区全交给自写代码）、
> 删掉"横屏强制 top=0"（本机横屏顶部有状态栏，37px 是真值）、键盘顶起自己补。

## 二 · 改了什么

- `apk/capacitor.config.json`：`insetsHandling: "css"` → **`"disable"`**（官方口径：把安全区完全交给
  自写代码；本作本来就是"壳自己量、页面自己躲"）。
- `MainActivity.java`：① **删掉"横屏强制 top=0"**（旧写法照另一台设备的经验；本机截图证明横屏顶部有
  真实状态栏）；② 新增 **`挂键盘垫起()`**（`disable` 后插件不再代劳键盘顶起，自己按 IME insets 垫
  `android.R.id.content` 的底部；不垫 decor，免得影响我们读 rootWindowInsets）。
- `city-life-framework.html`：安全区注释补两条实证结论；版本 v158 → **v159**。
- `harness.js`：第 159 单 3 条结构＋1 条反向自查（把 `disable` 改回 `css` ⇒ 当场判红）；登记表 **112 组**。
