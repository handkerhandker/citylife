# 第 124 单 · 提示音（零素材合成；有新的回信／留言时轻响一声）

> 一句话：游戏此前**完全没有声音**。本单补一条最小反馈——"他给你回话／留话"（未读角标从无到有或变多）时，
> 用 WebAudio **现场合成**一声轻响（880→1319Hz 双音、0.24 秒、峰值增益 0.045），设置页加「提示音 开／关」（默认开）；
> 首次用户点击才建 AudioContext（浏览器自动播放策略）。**纯 DOM 层**：三个指纹全原样，只有版本 v109 → **v110**。
