#### 3.3.1 天气系统：只有「下雨 / 不下雨」两态

`w.weather={rain:false, until:0}`（`:1087`）。导演层（`:1797–1804`）：

```js

  w.weather.rain=false; logSys(w,'雨停了，街道亮得像洗过。'); w.lastSpark=w.t;
```

- 单场时长：90 + 0/10/…/50 分钟（即 90–140 分钟）。

#### 3.3.2 雨在画面上是什么（唯一实现，`:3703–3713`）

```js
// 雨幕
if(state.world.weather.rain && !state.reduceMotion){
  rainSeed=(rainSeed+dtFrame*140)%40;
  ctx.strokeStyle='rgba(150,180,220,.28)'; ctx.lineWidth=1;

```

**逐项参数：**

| 项 | 值 |
|---|---|
| 形态 | **28 条贯穿全屏高的斜直线**（`i` 从 −2 到 25） |

### 3.4 镜头

**不是固定视角。** 现有三样：自动缩放、自动跟随、手动拖动平移。**没有手动缩放。**

#### 3.4.1 缩放：自动，由视口尺寸决定（`:3311–3320`）

```js
const fit=Math.min(box.width/Sim.MAPW, box.height/Sim.MAPH)*0.96;
// 地图整幅能看清就整幅显示；否则放大到可读的最小瓦片尺寸，镜头改为跟随+平移
state.view.s=Math.max(fit, Math.min(13, box.width/14, box.height/10));
```

- 地图幅面 47×28 格（`MAPW=47, MAPH=28`，`:512`）。
- `fit` ＝ 整幅塞进视口的格边长 × 0.96。
- 下限 ＝ `min(13, 视口宽/14, 视口高/10)` px/格——**保证至少能看清 14 格宽 × 10 格高的范围**。
- 取两者较大值：**宽屏上整幅可见；窄屏（手机）上自动放大、地图溢出视口，此时才进入跟随+平移模式。**
- DPR 适配：`dpr=Math.min(devicePixelRatio||1, 2.5)`（`:3313`）。
- 像素素材禁平滑：`ctx.imageSmoothingEnabled=false`（`:3604`）。
- **没有滚轮缩放、没有双指捏合、没有缩放按钮**（`grep wheel|pinch|gesturechange` 零命中）。
  设置页那个「100% ＋/−」（`:345–347`，范围 0.85–1.3，`:2581–2582`）调的是 CSS 变量 `--ui-scale`
  （**全站 UI 字号**），不是地图缩放。
- 浏览器自身的缩放也被关掉了：`:5` 的 viewport meta 逐字为
  `width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover`。

#### 3.4.2 跟随：跟着「当前选中的那个人」（`:3322–3336`）

```js
function updateCamera(dt){
  const v=state.view, mw=Sim.MAPW*v.s, mh=Sim.MAPH*v.s;
  if(!state.cam.manual){
    const tv=state.vis[state.selected];
    if(tv){
      const k=state.reduceMotion?1:Math.min(1, dt*5);
      state.cam.fx+=(tv.x-state.cam.fx)*k;
      state.cam.fy+=(tv.y-state.cam.fy)*k;
    }
  }
  v.ox = mw<=state.cvW ? (state.cvW-mw)/2 : PURE.clamp(state.cvW/2-state.cam.fx*v.s, state.cvW-mw, 0);
  v.oy = mh<=state.cvH ? (state.cvH-mh)/2 : PURE.clamp(state.cvH/2-state.cam.fy*v.s, state.cvH-mh, 0);
  const fb=$('#ov-follow');
  if(fb.hidden===state.cam.manual) fb.hidden=!state.cam.manual;
}
```

- 初值 `state.cam={fx:MAPW/2, fy:MAPH/2, manual:false}`（`:2126`）——开局对准地图中心。
- 跟随目标 ＝ `state.selected`（当前选中的住户），指数平滑 `k=min(1, dt*5)`；
  「减少动效」开时 `k=1`（瞬移，无缓动）。
- **地图整幅装得下时（`mw<=cvW`），镜头结果被居中覆盖，跟随不可见**——跟随只在窄屏放大时生效。

#### 3.4.3 手动平移：拖动（`:3715–3734`）

- 拖动阈值 8px；超过即 `drag.moved=true`。
- **只在地图溢出视口时才平移**（`if(Sim.MAPW*v.s>state.cvW || Sim.MAPH*v.s>state.cvH)`）；
  一旦拖动即 `state.cam.manual=true`，跟随停止。
- 平移量钳制在 `[0, MAPW]`／`[0, MAPH]`。
- `manual` 为真时右上角出现按钮 `◎ 回到跟随`（`:298–299`），点它 `state.cam.manual=false`（`:3763`）恢复跟随。

#### 3.4.4 点选（`:3740–3760`）

- 点按（未拖动）＝ 选中最近的小人；像素模式下测距锚点移到精灵**视觉中心**
  （`cyv += state.view.s*0.5 - (fh/fw)*state.view.s/2`，`:3752`），头部可点不退化。
- 命中半径 `max(18, view.s*0.9)`（`:3757`）。
- **没有双击聚焦、没有悬停高亮、没有房间点选。**

#### 3.4.5 页面结构

- 画布只有一个：`#cv`，在 `#scr-live`（现场页）内（`:294–296`）。

### 4.0 三条通用约束（每个候选项都要过）

1. **sim30 逐字节铁笼**（《云港建筑规范》五.2、《云港城市总规》六.2）：
   凡改动 `ROOMS`／`ANCHORS`／地图幅面／渲染层空间常量，改前改后 sim30 双种子输出必须**逐字节一致**，不一致一票否决。

   决策者目验管观感（`preview_shots.mjs` 截图前置），两道都过才算过。
   另：宪法第 27 条自陈「换一张 png 玩家看得见而 HTML 一字节不动」**不在涨号闸射程内**——纯素材单不涨号。
4. **两处已登记的无兜底同步点**（第 12 单 `:117` 实测所得，凡动放样的候选项都会碰上）：
   ① `preview_shots.mjs` 的摆拍坐标与裁剪区是蓝图镜像，**蓝图变更需手工同步**；
   ② `PIX_FURN_TALL` / `PIX_SOLID` 与 `build_assets.py` 登记表**仅人工对照、无 CI 兜底**。
5. **三条第 12 单指名留给二期任务书的口径**（见 2.6）：摊位真身首验、每门补「门洞跨度」字段、
   锚点离格与 `TILE=16` 死常量统一口径。
6. **四处站位的家具遮挡复核会自动到期**（第 20 单已知接受项 2，见 2.9）：
   `market`／`store_counter`／`park_bench`／`river_walk` 四处所在房间一旦上素材，
