## 第零章 授权红线（先读，三条）

1. 素材站上只放两张拼合成品图（apartment.png、characters.png），别的什么都不放。
2. LimeZu 原包里的任何文件永远不上传到素材站、永远不放进 GitHub 公开仓库——公开可下载等于二次分发，违反授权。原包只放在你自己的私有仓库里（仅施工会话经你授权读取，用毕留存或删除随你），私有仓库永不转公开。
3. 素材站不建首页、不建目录列表页；游戏里已带署名行「美术素材：Modern Interiors / Modern Exteriors by LimeZu（limezu.itch.io）」，无需另外署名。

补充口径（决策者 2026-08-03 认可）：两张拼合成品的网址公开可达，与游戏本体同等公开；素材站不含原包文件，即不构成对原素材的分发。原包经私有仓库中转短暂过境，同样不构成分发。

## 第一章 上传成品（三步，手机可完成）

1. **下载成品**：施工在会话里发给你两个文件——apartment.png 和 characters.png，保存下来（文件名必须保持全小写不变）。
2. **传到素材站**：打开 EdgeOne Pages 控制台（pages.edgeone.ai），进入 citylife-assets 项目，点「创建新部署」，新建一个空文件夹放入这两个文件，把整个文件夹拖进上传区，等部署完成（直传项目每次部署整包替换，旧文件自动消失）。
3. **验收**：浏览器分别打开下面两个网址，能看到两张图即成功：
   - https://assets.cydgames.com/apartment.png
   - https://assets.cydgames.com/characters.png
   然后打开游戏，进「设置」看「像素画风」一行右侧显示「已启用」；现场页里公寓变瓷砖、四个小人有形象、走路带动画。

若显示「素材未就位」：多半是两张图有一张打不开（用上面网址逐个排查）或文件名不对。游戏会自动用旧画风照常运行，不影响任何功能，修好素材刷新即可。

## 第二章 看不顺眼怎么改（挑剔通道）

四住户长相与房间摆设都是机器按角色气质自动选的部件，先斩后奏。你上线看过之后，任何不满意直接用自然语言告诉施工，例如：

- 「顾云帆头发换个颜色」「沈小满围裙换成橙色」
- 「卧室的床挪开一点」「客厅换深色地板」

施工改流水线里的对应参数、重跑机器、给你两张新图，你重复第一章三步上传覆盖即可。图片的行列规格与房间布局是游戏契约，挑剔只改观感、不动契约。
