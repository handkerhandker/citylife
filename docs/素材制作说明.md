# 素材制作说明（视觉层一期 · 公寓与四住户）

给谁看的：决策者本人，照着做即可，不需要任何绘图知识。
最终产出：两张图片文件 apartment.png 和 characters.png，上传到素材站。
需要准备：
- 一台电脑（角色生成器是电脑软件，手机做不了捏人和拼图这两步；建站和上传用手机也行）。
- 已购买的 LimeZu 素材完整版（Modern Interiors，含 Character Generator 角色生成器）。
- 浏览器（拼图用的 Photopea 是免费网页工具，不用安装、不用注册）。

## 第零章 授权红线（先读，三条）

1. 素材站上只放本说明产出的两张拼合成品图（apartment.png、characters.png），别的什么都不放。
2. LimeZu 原包里的任何文件（png、zip 等）永远不上传到素材站，也永远不放进 GitHub 仓库——公开可下载等于二次分发，违反授权。
3. 素材站不建首页、不建目录列表页；游戏里已带署名行「美术素材：Modern Interiors / Modern Exteriors by LimeZu（limezu.itch.io）」，无需另外署名。

补充口径（决策者 2026-08-03 认可）：两张拼合成品的网址公开可达，与游戏本体同等公开；素材站不含原包文件，即不构成对原素材的分发。

## 第一章 先把素材站建起来（EdgeOne 控制台）

### 1.1 创建「直接上传」型项目

1. 浏览器打开 EdgeOne Pages 控制台（和部署游戏用的是同一个后台）：
   https://pages.edgeone.ai
2. 点「创建项目」。
3. 创建方式选「直接上传」——注意：不要选「导入 Git 仓库」。
4. 项目名填：citylife-assets
5. 加速区域选：全球可用区（不含中国大陆），和游戏项目保持一致。
6. 上传区先拖进一个随便的文本文件（比如电脑上新建的空白 txt）完成创建——平台要求至少有一个文件；第四章正式上传时会整包替换掉它，不会残留。
7. 点创建，等部署完成。

### 1.2 绑定子域名 assets.cydgames.com（这一步不能省）

说明：项目自带的默认网址从中国大陆访问必返错误页（平台合规设计，不是故障，游戏站当初也遇到过），所以必须绑自己的子域名。

1. 进入刚建好的 citylife-assets 项目。
2. 找到「域名管理」（或「自定义域名」），点「添加域名」。
3. 填入：assets.cydgames.com
4. 平台会给出一条 CNAME 记录值（一长串网址样子的字符），完整复制它。
5. 新开一个标签页，登录 DNSPod（管理 cydgames.com 解析的地方，游戏站域名当初也在这里配）：
   https://console.dnspod.cn
6. 找到 cydgames.com，点「添加记录」。
7. 「主机记录」填：assets
8. 「记录类型」选：CNAME
9. 「记录值」粘贴第 4 步复制的那串字符。
10. 保存，回到 EdgeOne 标签页，等状态变成已生效/已激活（一般几分钟）。

### 1.3 自检

1. 浏览器打开：
   https://assets.cydgames.com/
   显示 404 或空白页都算正常（我们故意不做首页）；只要不是「无法访问此网站」就说明域名已通。

## 第二章 做 characters.png（四位住户的行走图）

### 2.1 布局铁律（拼错了游戏里会串人，先看懂再动手）

最终的 characters.png 是把 8 条长图从上到下摞成一张：

| 第几条 | 内容 |
|---|---|
| 1 | 顾云帆 站立（idle） |
| 2 | 顾云帆 行走（walk） |
| 3 | 沈小满 站立 |
| 4 | 沈小满 行走 |
| 5 | 陆知秋 站立 |
| 6 | 陆知秋 行走 |
| 7 | 白一鸣 站立 |
| 8 | 白一鸣 行走 |

- 每条长图自身是 24 帧连成一横排：面向右 6 帧、面向上 6 帧、面向左 6 帧、面向下 6 帧——这是生成器导出的原样顺序，不用改，也千万别改。
- 八条的宽度必须全部一样、高度必须全部一样。
- 游戏按「总宽 ÷ 24、总高 ÷ 8」自动切帧，所以 16/32/48 像素档导出的都能用；推荐 48 像素档（3×），四个人务必用同一档。

### 2.2 捏人（Character Generator 角色生成器）

1. 打开完整版素材包附带的 Character Generator（Windows 上双击运行）。
2. 按下表逐一捏四个形象（发型、衣服在生成器里点选即可）：

| 住户 | 形象口径 |
|---|---|
| 顾云帆（程序员） | 短发，神色疲惫，休闲T恤或格子衫，蓝灰色系 |
| 沈小满（便利店店员） | 马尾辫，围裙，亮色系（粉/橙），带笑 |
| 陆知秋（交易员） | 衬衫西裤，头发一丝不苟，深色冷色系 |
| 白一鸣（自由撰稿人） | 乱发，居家服睡衣感，暖色或绿色系 |

3. 每捏好一个人，用生成器的导出功能，把该角色的「idle（站立）」与「walk（行走）」两条动画分别导出为 png，尺寸选 48px（3×）档。
4. 导出后立刻改名，防止搞混（共 8 个文件）：
   1-guyunfan-idle.png、2-guyunfan-walk.png、3-shenxiaoman-idle.png、4-shenxiaoman-walk.png、5-luzhiqiu-idle.png、6-luzhiqiu-walk.png、7-baiyiming-idle.png、8-baiyiming-walk.png
5. 如果生成器导出的不是单条动画而是一整张全动作大图，或者一条动画被分成四小条（右/上/左/下各一条）：不用慌，先把 8 个人物动画对应的原始导出文件都存好，再看附录A 裁拼成标准长条。

### 2.3 拼合（Photopea 免费网页工具）

目标：把 8 个文件按编号从上到下拼成一张 characters.png。

1. 浏览器打开：
   https://www.photopea.com
2. 菜单「文件」→「新建」：宽度填单条图的宽度（48px 档是 1152），高度填单条高度乘 8（48px 档是 96×8＝768），背景选「透明」，点创建。
   （不确定单条尺寸？把 1 号文件拖进 Photopea 打开，标签页上就写着它的宽×高。）
3. 菜单「文件」→「打开并置入」，选 1 号文件，按回车确认置入。
4. 菜单「编辑」→「自由变换」，在顶部工具条把 X 填 0、Y 填 0，按回车两次。
5. 重复第 3–4 步处理 2 到 8 号文件，每次只有 Y 值不同（48px 档按下表；其他档位 Y＝单条高度×(编号−1)）：

| 文件编号 | Y 值 |
|---|---|
| 1 | 0 |
| 2 | 96 |
| 3 | 192 |
| 4 | 288 |
| 5 | 384 |
| 6 | 480 |
| 7 | 576 |
| 8 | 672 |

6. 菜单「文件」→「导出为」→「PNG」，文件名填 characters，保存。得到 characters.png。

### 2.4 自检

1. 打开 characters.png 预览：从上到下 8 条，顺序是 顾/顾/沈/沈/陆/陆/白/白；第 1、3、5、7 条是站立，第 2、4、6、8 条有迈腿走路动作。
2. 图片的高度应恰好是宽度的三分之二（例如 1152×768）——不对就是某条尺寸不一致，回 2.3 重拼。

## 第三章 做 apartment.png（公寓拼合图）

### 3.1 尺寸与布局（按格子说话，左上角是第 1 列第 1 行）

- 整张图 768×432 像素：横 16 格 × 竖 9 格，每格 48 像素。
- 房间划分：
  - 客厅：第 1–10 列 × 第 1–9 行（左侧大间）
  - 厨房：第 11–16 列 × 第 1–4 行（右上）
  - 卧室：第 11–16 列 × 第 5–9 行（右下）
- 三个门洞（务必留成开口或摆门，别画成实墙，住户要从这里走）：
  - 客厅下边缘：第 6 列
  - 卧室下边缘：第 13 列
  - 厨房与卧室之间的隔墙（第 13 列、第 4 行与第 5 行交界）：留一个门洞（住户从厨房出门会穿过卧室）
- 家具建议（对应住户活动位置，差一格没关系，大致对上即可；样式随喜好挑）：

| 家具 | 位置（列,行） |
|---|---|
| 客厅餐桌 | 5,5 |
| 沙发与电视 | 3,2–3 |
| 写作角书桌 | 8–9,2–3 |
| 厨房灶台 | 13,2–3 |
| 床一（卧室左上） | 12,6 |
| 床二（卧室右上） | 15,6 |
| 床三（卧室左下） | 12,8 |
| 床四（卧室右下） | 15,8 |

### 3.2 素材从哪来

用完整版 Modern Interiors 包里 48×48 档的室内图块（地板、墙、床、桌椅等）。只在 Photopea 里打开取用，原文件不上传到任何网站。

### 3.3 Photopea 拼装步骤

1. 打开 https://www.photopea.com
2. 「文件」→「新建」：宽 768、高 432、背景透明，创建。
3. 「视图」→「显示」→勾选「网格」；再到「编辑」→「首选项」→「参考线、网格」把网格间距设为 48 像素——之后画面上每个小方格就是一格，对着格子摆就不会歪。
4. 「文件」→「打开」，打开素材包里的地板图块文件。
5. 选「矩形选框工具」（快捷键 M），框住一块地板，「编辑」→「复制」。
6. 切回拼图那个标签页，「编辑」→「粘贴」，按 V 换移动工具，拖到目标格子。
7. 铺满一间房的诀窍：粘贴到位后按住 Alt 键拖动即可原地快速复制，重复到铺满。先铺客厅，再厨房、卧室；三间房可用不同地板花色区分。
8. 用同样的「框选→复制→粘贴→拖到位」贴出四周外墙和房间之间的隔墙，并在 3.1 标注的三个门洞位置留出缺口或摆门。
9. 按 3.1 的家具表把床×4、餐桌、沙发电视、书桌、灶台摆进去。
10. 「文件」→「导出为」→「PNG」，文件名填 apartment，保存。得到 apartment.png。

说明：这一章是纯手工拼贴，第一次做预计一两个小时；拼得糙没关系，先让游戏跑起来，之后随时可以重拼、重新上传覆盖。

### 3.4 自检

- 尺寸恰为 768×432。
- 三个门洞没被实墙堵死。
- 成品是你自己拼的房间，不是原包里的整张展示图（直接用展示图属于分发原素材，踩红线）。

## 第四章 上传两张成品图

1. 电脑上新建一个空文件夹，起名 citylife-assets-upload。
2. 把 apartment.png 和 characters.png 放进去，只放这两个文件。
3. 打开 EdgeOne Pages 控制台，进入 citylife-assets 项目。
4. 在部署页点「创建新部署」。
5. 把整个文件夹拖进上传区（直传项目每次部署都是整包替换，第一章的占位文件会自动消失）。
6. 等部署完成（一般一两分钟）。

## 第五章 验收自检（两分钟）

1. 浏览器分别打开下面两个网址，能看到两张图即成功：
   https://assets.cydgames.com/apartment.png
   https://assets.cydgames.com/characters.png
2. 打开游戏，进「设置」，看「像素画风」一行右侧显示「已启用」。
3. 回到现场页：公寓显示成你拼的房间，四个小人变成捏好的形象，走路带动画，点小人能弹出角色卡。
4. 若显示「素材未就位」：多半是两张图有一张打不开（用第 1 步网址逐个排查），或文件名不对（必须全小写的 apartment.png 与 characters.png）。此时游戏自动用旧画风照常运行，不影响任何功能；修好素材后刷新页面即可。
5. 两张图缺一张，游戏就整体回旧画风——这是设计好的保底，不是故障。

## 附录A 生成器导出格式不是单条 24 帧长图时怎么办

情况一：导出的是一整张全动作大图（idle、walk、跑步、坐下等都在一张里）。

1. 把大图拖进 Photopea 打开。
2. 找到站立那一横排（小人基本原地不动）和行走那一横排（有明显迈腿），一排应是 24 帧。
3. 用矩形选框工具框住整条站立排（48px 档：宽 1152、高 96；框选时 Photopea 右上会显示选区宽高），「编辑」→「复制」。
4. 「文件」→「新建」（宽 1152、高 96、透明底）→「编辑」→「粘贴」→「文件」→「导出为」→PNG，按 2.2 的编号命名保存。
5. 行走排同样操作；每个角色重复，凑齐 8 个文件后回到 2.3。

情况二：一条动画被拆成四小条（面向右/上/左/下各 6 帧）。

1. 「文件」→「新建」：宽＝小条宽×4（48px 档是 288×4＝1152），高＝小条高（96），透明底。
2. 依次「打开并置入」四个小条，用「编辑」→「自由变换」把 X 分别填 0、288、576、864（Y 都是 0），顺序必须是 右、上、左、下。
3. 导出为 PNG，按 2.2 的编号命名；重复凑齐 8 个文件后回到 2.3。
