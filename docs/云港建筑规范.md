# 云港建筑规范
制定:第 11 单(甲案地图骨架重整,v25)· 与三件套同等效力

本规范是云港一切空间放样的铁律。适用于既有与未来全部房间、街区、地图改动;任何放样单(视觉层二期全城铺装及其后)开工前必须先对照本规范,违反本规范的蓝图不得开工。

## 一、尺度基准

1. 1 格 = 48 像素(48px 档素材,与 TILE 渲染换算无关,此处指世界格的素材像素密度)。
2. 人物精灵占 1×2 格(宽 42–48px 近满格,高 2 格)。因此宽 1 格的通道是零余量下限——放样时一律不得按 1 格通道设计。

## 二、通道铁律

1. 单人通道 ≥2 格。
2. 主干道 / 双人对向通道 ≥3 格(街道纵深按此执行)。
3. 门洞 ≥2 格。
4. 家具之间的走道 ≥2 格(专项条款另有明示者除外,如卧室床间距条款)。
5. 计量口径:通道与门洞按世界格计;墙面描边(竖条 21px/横条 18px)是墙体自身厚度,不计入通道扣减,但描边之间的净道必须 ≥ 人宽 48px 并有断言兜底。

## 三、贴墙铁律

1. 家具顶部搭墙 ≤6px(LimeZu 标准搭法:家具上缘至多压入墙带下缘 6px)。
2. 侧墙零重叠:任何家具与竖向墙体/描边零像素重叠。
3. 墙体像素不可侵占:「墙体完整性」断言永久生效——空房仅墙基准中属于墙/描边/窗的每一个像素,在成品中必须逐像素一致,家具层零改写。
4. 窗户属墙体构件层:随墙入「空房仅墙」基准,不算家具;窗下沿越出墙带的视觉延伸部分同受墙体完整性保护。

## 四、放样铁律

1. 房间尺寸由「家具真身 + 通道预算」正向反推;禁止先定房间再削家具或压缩通道(反向削足)。
2. 家具按真实像素放样(整件登记表四元组:名称→源图区域→整件宽高→落位;整件±0 断言兜底);锚点按格登记(SIM 锚点坐标以世界格计)。
3. 每类房间放样前先出「家具占位表」(件名/真身宽高/落位格/占格登记),表未出不落样。

## 五、效力与维护

1. 本规范与 宪法.md/交接说明.md/待办.md 三件套同等效力,随交付同步维护。
2. 坐标类改动(ROOMS/ANCHORS/地图幅面/渲染层空间常量)永久适用 sim30 逐字节铁笼:改动前后 sim30 双种子输出必须逐字节一致,不一致即一票否决。
3. 修订本规范须任务书明确授权,修订入档附缘由。
