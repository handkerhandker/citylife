# 关系状态机 · 二期方案 v1（**待决策者点头才动工**）

> 一句话：本作现在**只记"聊过几次"**（`w.stats.pair`，第 67 单已摆到角色页上）。
> 二期要加的是**会涨会落的关系值**：每天第一次说话才加分、长期不联系缓慢回落、涨到档位就说法的口吻不一样。

## 三 · 设计（三件东西：一个值、一张档位表、三处外显）

### 3.1 数据形状（**新增一处世界状态**，这是本方案唯一的"改结构"）

```js
ag.rel = { a2:{v:38, day:412}, a3:{v:12, day:404}, ... }   // 每对关系一个值；day＝最后一次"当面说话"的日号
```

- **只存"他视角"的半张表**（a1→a2 与 a2→a1 各自一份）：关系本来就是双向的，A 觉得熟、B 未必。
- 旧档缺字段＝**就地补 0**（照 `goalOf`／`rhyRest` 那样"宁可缺省也不判坏档"）。
- 与既有 `w.stats.pair` 的关系：**不合并**。前者是"说过多少话"的原始账（剪辑层在用），后者是"关系深浅"的派生值。

### 3.2 涨落规则（照调研，全部**确定性**、零 AI、零随机）

| 事件 | 变化 | 出处口径 |
|---|---|---|
| 当天**第一次**和某人说话 | **+1**（同一天再聊不加） | 动森「first time each day」 |
| 生日那天对他说了祝福（第 65 单那一支） | **+3** | 星露谷"生日 ×8"的映射（我们取一个小整数倍） |
| 收到玩家的「生日快乐」短信（第 64 单） | 他自己的关系值不动（玩家不在四人之间）；只进周记忆 | 现状 |
| **连续 3 天**没和某人说过话 | 第 4 天起每天 **−1**，**落到本档下限就停** | 星露谷"不打招呼就掉，到档位停" |
| 上限 | **60**（够走满五档；不再往上） | 动森 0–255、星露谷 0–3749 都只是尺度，我们不需要那么细 |
| 下限 | **0**（不出现负关系） | 本作定位是"看人过日子"，不做好感负分 |

**不夺走口径**：关系回落**只动这一个数**——不许扣钱、不许扣饭、不许影响上班与睡觉（照第 22／46／49 单那条红线）。

### 3.3 档位表（五档，边界写死，透明可算）

| 档 | 值 | 口吻／后果（**A 档先只做口吻与外显**） |
|---|---|---|
| 生疏 | 0–9 | 现有台词不变 |
| 点头之交 | 10–19 | 角色页那一行开始报档位 |
| 熟 | 20–34 | 角色页写"和 X 挺熟" |
| 老友 | 35–49 | 剪辑层多一档判据（"今天和他聊了很久"） |
| 家人一样 | 50–60 | 生日那天他一定会去道贺（现在靠"同屋且空闲"） |

### 3.4 外显（三处，都不新增素材）

1. **角色页／角色详情**：第 67 单那行「常聊」升级为「和 X · 熟（28）」。
2. **剪辑层**：新增两项——`rel_up`（这天和谁的关系涨到新档）／`rel_cold`（连续五天没说话）。权重照第 54 单那张表登记。
3. **周记忆**：每周压一句（"这周和陆知秋说了四回话"）。

## 五 · 验收口径（A 档）

1. **构造**：把一对人的关系推到档位边界（9／10、19／20、34／35、49／50），断言档位名与文案逐个对得上。
2. **涨落**：构造"连续三天说话"⇒ 每天只加一次（同日第二场不加）；构造"连续五天不说话"⇒ 从第 4 天起每天 −1、落到档位下限停。
3. **不夺走**：跑 400 天 × 3 种子，断言钱／饭／上班／睡眠四项读数与上一版**逐条不变**（关系只动自己那一个数）。
4. **旧档**：喂一份缺 `ag.rel` 的存档 ⇒ 就地补 0、不报错、不丢别的字段。
5. **确定性**：同种子逐字可复现；关系值不参与任何 `w.rng()` 抽取。
6. **外显**：双档截图 ＋ 全按钮扫描；角色页那一行在五人六档下排版不越界。

## 七 · 本方案明确不做（免得起争议）

- 不做**恋爱／结婚／多人好感互斥**（本作是"看四个人过日子"，不是养成对象）。
- 不做**用钱买关系**（钱包只管吃住）。
- 不做**负关系／仇视**（下限 0）。
- 不做**关系数值的交易化**（呼应母法：收费只卖支持不卖强度）。
