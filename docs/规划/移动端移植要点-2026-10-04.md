## 二 · 出处与原文

### 出处一 · Capacitor（App 插件 API）

地址：https://capacitorjs.com/docs/apis/app （2026-10-04 HTTP 200）

原文（逐字摘）：
> `App.addListener('appStateChange', ({ isActive }) => { … })`
> `disableBackButtonHandler` boolean … **Only available for Android.**

另有上批已核的 Android 支持面（https://capacitorjs.com/docs/android ）：
"API 24+ (Android 7 or later) … around 99% of the Android market"；
"requires an Android WebView with Chrome version 60 or later"。

**抄哪一条**：返回键与前后台切换都有官方事件可用；最低支持 Android 7（覆盖 ~99% 机型）。

### 出处二 · MDN · CSS env()

地址：https://developer.mozilla.org/en-US/docs/Web/CSS/env （2026-10-04 HTTP 200）

原文（逐字摘）：
> …**to place their content in a safe area of the viewport, and not be obscured by device notches
> or rounded corners**, the `safe-area-inset-*` values can be used…

**抄哪一条**：刘海／圆角／手势条用 `env(safe-area-inset-*)`（配合 `viewport-fit=cover`）留白。

### 出处三 · Android Developers · edge-to-edge

地址：https://developer.android.com/develop/ui/views/layout/edge-to-edge （2026-10-04 HTTP 200）

原文（逐字摘）：
> Once you **target SDK 35 or higher** on a device running **Android 15** or higher, your app is
> displayed **edge-to-edge**. The window spans the entire width and height of the display by
> drawing behind the system bars.

**抄哪一条**：Android 15 起**强制全屏铺满**——安全区必须自己处理，否则顶栏顶到状态栏、
底栏压在手势条下。
**不抄**：锁死横竖屏、沉浸式全屏（本作有常驻顶栏，不需要）。

## 三 · 施工清单（做 APK 时照这个走）

1. **壳**：Capacitor；把 HTML 与两张素材打进 App（离线优先）。
2. **返回键**：`App.addListener('backButton')` → 接游戏自己的返回（先关面板/弹窗，再退出），
   不要一按就退。
3. **前后台**：`appStateChange` → 回前台刷新（离线补算本来就有，只需确认触发）。
4. **安全区**：`env(safe-area-inset-*)` 给顶栏/底栏留白；`viewport-fit=cover`。
5. **AI**：默认模板兜底；要走 DeepSeek 就把内置的"AI 中转地址"指向自建 `/relay`
   （上一轮已实测：DeepSeek 允许浏览器跨域、`/relay` 自带 CORS）。
6. **存档**：WebView 的 localStorage；卸载即清（已有 CLS1 导出/导入码可备份）。
7. **网络**：全 https；若允许自定义 http 地址，需显式开 cleartext（默认不开）。
8. **更新**：内置 HTML ⇒ 新版本重装 APK（离线优先的代价）。

## 四 · 验收计划（两条腿）

- **真机**：装 debug 包 → 图标开机 → 现场页 → 点选/拖动 → 六页签 → 短信/加急 →（若做电话）
  通话三结局 → 切前后台 → 返回键 → 锁屏解锁 → 导出/导入存档 → 转屏（若允许）。
- **对照**：同一份 HTML 在桌面浏览器再跑一遍现有 22 张巡查图＋五回归，确认"壳里壳外"一致。

## 五 · 风险登记

1. **Android 15+ 强制 edge-to-edge**（硬要求，必须处理安全区）。
2. 老机型 WebView 版本（Chrome 60+）；最低 Android 7。
3. AI 的额度与密钥归属（走中转＝你出钱，另文）。
