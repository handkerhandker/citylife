## 一 · 装包

1. **装哪个**：看 `outputs\README-交付清单.md` 的「该装哪个」——永远装 versionCode 最大的那个
   （v158 ＝ 1158）。**装的时候应该显示「更新」**（不是"已安装"），因为 v145–v155 的老包
   升级号全是 1，有些安装器会把"同号"当成"已安装、不替换"（第 191 单）。
2. **装完第一步**：进游戏 → 设置 →「构建版本」应是最新号（现在应为 **v158**）。
   - 还是旧号 ⇒ **包没换上**：先在旧版「设置 → 存档 → 导出」存好**存档码**，再卸载重装、把码贴回「导入」。
3. **第二步**：设置里把「诊断浮层」打开。浮层里若**看不到 `屏`／`壳`／`设备`** 这几段，说明跑的还是
   旧页面（缓存/没换上）——回来告诉我。

## 二 · 浮层每一行怎么读

| 行 | 内容 | 判读 |
|---|---|---|
| 第 1 行 | 视口（WebView 的 CSS 尺寸）· dpr · 布局档 · **屏**（物理屏的 CSS 尺寸） | **视口 = 屏**才算 WebView 铺满。视口 < 屏 ⇒ **有东西在缩 WebView**：①先查 SystemBars 插件（**第 204 单根因**：WebView<140 时它会把整个 WebView 塞进安全区——源码 `decor.setPadding`；已用 `insetsHandling:"disable"` 关掉）；②关掉后仍不等 ⇒ 才轮到容器 letterbox |
| 第 2 行 | **安全区**（页面实际用的 `--sa-*`）＋**平台**（SystemBars 注入值）＋**壳**（安卓壳量的值，`(备)`＝用系统声明值兜底） | 见下面「三种断点」 |
| 第 3 行 | 画布尺寸（含 buf）· 地图尺寸与落点 · **边带 t/b/l/r** | 边带＝四边各空多宽。**哪一侧有黑边，看这一行** |
| 第 4 行 | 当前屏（含弹窗开） | — |
| 第 5 行 | 帧率／p95／缩放／速度 | 缩放＝地图缩放；帧率低＋GPU 是软件渲染 ⇒ 性能问题 |
| 第 6 行 | 设备：内存 · **内核**（WebView 版本）· GPU · vv（visualViewport 尺寸@缩放） | **vv scale ≠ 1.00** ⇒ 页面被缩放/双指放大过 |

### 三种"顶栏被盖"的断点（对第 2 行）

1. **页面 t=0 ／ 平台 t>0** ⇒ 平台给了值、页面没用上：看 CSS 优先链（186 单配方被改坏）。
2. **页面 t=0 ／ 平台 t=— ／ 壳 t>0** ⇒ 壳量到了但**没送进页面**：投递断了（190 单的"两条腿"：壳推＋页面主动问）。
3. **页面 t=0 ／ 壳 t=0(不带备)** ⇒ **宿主压根不报数**，且系统声明值也取不到：这种情况要另找来源（把截图给我）。
   若壳显示 `t.. (备)` 而页面仍是 0 ⇒ 兜底算出来了但投递没到（同 2）。

### "WebView 太老"这道坎（对第 6 行"内核"）

Capacitor 官方口径（186 单引）：**安卓 WebView < 140 时 `env(safe-area-inset-*)` 拿不到值**。
所以：内核 < 140 且平台值缺失 ⇒ 只能靠壳侧的 `(备)` 兜底那条路。

### "横屏三边空"的读法（对第 1／3 行）

- **视口 < 屏** ⇒ 画面外的带子是容器留的（改不了应用内布局，只能改容器/声明）。
- **视口 = 屏、边带 t/b/l/r 有非 0** ⇒ 带子在**画布内**：哪边是多少，就说明地图没铺到哪边（第 186 单的"铺宽"口径可据此调）。

## 三 · 常见组合 → 下一步

| 现象 | 先看 | 下一步 |
|---|---|---|
| 顶栏被状态栏盖 | 第 2 行三套值 | 按上面「三种断点」对号；把截图发我 |
| 横屏三边深色带 | 第 1 行（视口 vs 屏）＋第 3 行边带 | 视口<屏 ⇒ 插件在缩（204 单已关）或容器 letterbox；视口=屏且边带非 0 ⇒ 画布内没铺到，调"铺宽/裁切"；**视口=屏、边带=0 却还有一条深色带 ⇒ 看是不是壳自己的"顶部渐隐层"（`MainActivity` 的 `顶渐隐`，它按状态栏高度盖一条纯底色——设计如此，要全透可改）** |
| 画面糊／卡 | 第 5／6 行（帧率、GPU、vv scale） | 软件渲染或缩放异常，把截图发我 |
| 装了没变化 | 设置里"构建版本" | 仍是旧号 ⇒ 导出存档→卸载→重装→导入 |

## 四 · 兜底三件套

1. **存档码**：任何"卸载/重装/换机"之前，先在「设置 → 存档 → 导出」存一份码（卸载会清本机存档）。
2. **旧包**：`outputs\历史\` 里按版本号都留着（近五版在顶层）。
3. **诊断截图**：浮层开着，竖屏、横屏各一张——一页就能说清卡在哪一环。
